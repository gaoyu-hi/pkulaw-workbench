# 数据备份与恢复（0.2.3）

## 备份

1. 关闭法宝工作台；
2. 找到发布目录下的 `数据` 文件夹；
3. 完整复制 `数据` 文件夹到备份位置；
4. 建议同时保存发布包 SHA-256。

必须保留：

- `pkulaw.sqlite3`；
- `pkulaw.sqlite3.pre-v6-*.bak`（从旧版升级时自动生成的迁移前快照）；
- `logs/`；
- 配置和 Session 分区；
- 任务输出目录及其中 Word、TXT、CSV、XLSX、HTML、PNG 和 JSON 证据。

## 恢复

1. 关闭应用；
2. 将备份的 `数据` 文件夹复制回发布目录；
3. 启动应用；
4. 在“设置与诊断”检查 SQLite integrity；
5. 在任务中心检查任务状态和输出目录。

不要在应用运行期间直接复制 SQLite 主文件，因为 WAL 文件可能尚未合并。

## 从旧版本升级

1. 先完整备份旧版 `数据` 文件夹；
2. 启动 0.2.3；
3. 确认数据库同目录产生 `pkulaw.sqlite3.pre-v6-*.bak`；
4. 在设置与诊断页确认 schema v6 和 `integrity_check=ok`；
5. 不把 v6 数据库直接交给旧版本使用。

## 只恢复任务数据库

如果只恢复 SQLite 而没有恢复产物文件，任务可能显示完成但文件核验失败。正式恢复应同时保留数据库、文件、证据和哈希。
