# 安装与卸载（0.2.2）

## 安装

当前交付为免安装 Windows 便携版，不写系统服务，不安装 Python。

1. 将 ZIP 解压到本机可写目录；
2. 不要把 ZIP 放在只读共享盘或直接在压缩包内运行；
3. 双击 `启动法宝工作台.cmd`；
4. 首次启动等待后端握手；
5. 打开“设置与诊断”确认预检。

0.2.2 首次打开旧版数据库时，会在数据库同目录生成：

```text
pkulaw.sqlite3.pre-v6-<时间>.bak
```

迁移完成后数据库为 schema v6。旧版本不保证读取 v6 数据库；
需要回退版本时，应先备份整个 `数据` 文件夹。

如需放在多人共用的 Program Files 目录，应确保普通用户对数据目录有写权限；更推荐每个用户解压到自己的目录。

## 卸载

1. 关闭应用；
2. 如需保留任务数据，先备份 `数据` 文件夹；
3. 删除整个发布目录；
4. 如曾通过其他方式直接启动 EXE，可另行检查当前用户 AppData 下的 Electron/法宝工作台数据目录。

便携版没有系统级卸载器，也没有后台服务残留。
