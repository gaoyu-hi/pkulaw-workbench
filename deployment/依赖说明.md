# 依赖说明（0.2.4）

## 发布包已包含

- Electron 45.2.1 桌面运行时；
- Chromium 156；
- Python 3.14.7 自包含后端 `resources/engine/pkulaw-engine.exe`；
- 内置离线 antiword 0.37 及其许可证、源码说明；
- DrissionPage 4.1.1.4；
- python-docx 1.2.0；
- openpyxl 3.1.5；
- xlrd 2.0.2；
- SQLite；
- React 19.3.1；
- fflate 0.8.3。

目标电脑不需要安装 Python、DrissionPage 或 Node.js。

## 系统要求

- Windows 10/11 x64；
- 至少 1 GB 可用磁盘空间；
- 能访问学校 VPN 或机构入口；
- 允许应用打开自己的内置 Chromium 页面；
- 不要求安装外部 Edge。

## 旧版 DOC

DOCX 始终可处理。旧版 `.doc` 优先使用发布包内置的离线 antiword；
内置转换器缺失、损坏或版本不符时失败关闭，并可诊断后续系统后备方案。
目标电脑不需要安装 Python、LibreOffice 或 Microsoft Word。

## 完整锁定

构建环境的完整 Python 包版本见源码目录：

`engine/requirements-lock.txt`

运行时直接依赖见：

`engine/requirements.txt`
