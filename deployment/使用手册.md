# 法宝工作台 0.2.2 使用手册

## 内置浏览器

- 机构页面、登录页、滑块、北大法宝和政府官网均在 Electron 内显示；
- 每个机构使用独立持久 Session；
- 账号和密码由使用者本人输入；
- IP 登录只需在学校入口点击相应登录方式；
- 校外访问通常需要先连接学校 VPN。

## 逐篇采集

适合标题清单或需要逐条核对同名版本的场景。

1. 选择中央、地方或分别检索；
2. 默认使用关键词；“精确完整标题”只用于逐篇任务；
3. 设置年份、省份、时效性、分页和输出目录；
4. 先执行“预览（0 下载）”，确认组合数、结果数、页数和下载数；
5. 启动任务；
6. 遇到登录、滑块或同名版本时人工处理；
7. 在任务中心查看逐条结果。

年份支持全部年份、单年和起止区间。单年与区间年份可直接键盘输入，范围为 1949 至当前年份。单篇和批量的检索条件会在页面切换后保留。

“预览（0 下载）”会真实检索，但不会打开详情或创建下载。它用于核对结果数、总页数、结果窗口、登录状态和选择器；修改条件后必须重新预览，启动按钮才会开放。

分页支持“扫描到尾页”和“指定页数上限”；达到上限但结果尚未结束时，任务会等待你选择“继续到尾页”或停止，不会把截断结果标记为完成。

## 批量采集

1. 批量固定使用关键词，先执行“预览（0 下载）”；
2. 设置检索条件和每页条数；
3. 每批最多 50 条；
4. 程序先取得网站原生 XLS，再在需要时生成“本地转换 XLSX”或“兼容 HTML-XLS”；
5. 程序调用 Word ZIP 并执行完整性校验；
6. 自动校验目录、ZIP CRC、数量、空文件、重复项和路径穿越；
7. 失败批次隔离，可在任务中心重试；
8. 批量扫描前和首批结果后会显示预计页数、政策数、50 条批次数和年度组合；
9. 规模达到阈值时必须人工确认，确认前不会创建或下载批次。

## 数据与报告

1. 选择已经完成或部分完成的源任务；
2. 点击“生成数据包”；
3. 按来源和状态筛选逐条记录；
4. 可直接打开 Word、TXT、来源证据、CSV、XLSX 和任务报告；
5. 政府官网补全需要逐篇精确标题任务并显式勾选。

## 任务中心

- 按模式、状态和关键词筛选；
- 查看逐条状态、当前阶段和错误；
- 同名政策由使用者选择具体版本；
- 停止、继续和重试；
- 手动暂停、自动暂停、继续和停止；
- 年份、页数和组合断点；
- 任务多选、归档、回收站恢复和彻底删除；
- 查看批量断点；
- 打开任务输出目录和最新数据产物。

## 设置与诊断

启动后端就绪后会自动预检，也可以手动重新诊断：

- Python 与 DrissionPage；
- SQLite 完整性；
- 数据和日志目录；
- 机构入口网络；
- 当前显示缩放；
- 内置/外部 Python 模式；
- 磁盘空间和依赖版本；
- 内置网页 50%–200% 缩放状态。

## 分页和规模确认

- 分页上限按每个检索组合独立计算；
- “继续到尾页”会为当前任务持久保存；
- 停止时保留当前年度、页码、已扫描页数和未扫描页数；
- 批量规模达到 20 页、500 条政策或 5 个批次时要求确认；
- 登录、额度、验证码、页面结构异常不会因普通“继续”被放行。

## 数据保留

使用 `启动法宝工作台.cmd` 时，数据位于发布目录的 `数据` 文件夹。迁移或备份前先关闭应用，再复制整个 `数据` 文件夹。
