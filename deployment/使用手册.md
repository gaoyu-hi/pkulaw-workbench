# 法宝工作台 0.2.4 使用手册

## 界面与机构登录

- 侧边栏不再有独立“内置浏览器”入口；
- 在“总览”顶部保存机构名称和授权入口，并直接打开右侧浏览器登录；
- 已认证后浏览器自动收起，只显示机构状态卡；切换账号或重新检测时再打开；
- 机构页面、登录页、滑块、北大法宝和政府官网均在 Electron 内显示；
- 每个机构使用独立持久 Session；
- 账号和密码由使用者本人输入；
- IP 登录只需在学校入口点击相应登录方式；
- 校外访问通常需要先连接学校 VPN。

## 逐篇采集

适合标题清单或需要逐条核对同名版本的场景。

1. 先在总览完成机构配置和登录；
2. 进入逐篇采集，选择中央、地方或分别检索；
3. 选择匹配方式：关键词、全文或精确完整标题；
4. 设置年份、省份、时效性、分页和输出目录；
5. 点击唯一的“创建并开始逐篇采集”；
6. 任务与内置浏览器在同一屏左右显示，隐藏核验期间下载数始终为 0；
7. 遇到登录、滑块或同名版本时直接在右侧浏览器人工处理；
8. 运行中可打开“任务设置”，浏览器会自动收起；关闭或应用后恢复。

年份支持全部年份、单年和起止区间。单年与区间年份可直接键盘输入，范围为 1949 至当前年份。单篇和批量的检索条件会在页面切换后保留。

单篇的匹配方式与北大法宝字段对应如下：

| 界面选项 | 北大法宝字段 | 匹配方式 | 用途 |
|---|---|---|---|
| 关键词 | 标题 | 精确 | 按标题关键词检索；同名但政策 ID 不同则分别保留 |
| 全文 | 全文 | 精确 | 按政策全文关键词检索 |
| 精确完整标题 | 标题 | 精确 | 逐篇精确核对；同名版本由人工选择 |

批量只提供“关键词”和“全文”，分别对应“标题 + 精确”和“全文 + 精确”。批量不提供精确完整标题模式。

法规子库会决定省份选项是否显示：选择“中央法规”时省份控件隐藏，程序实际使用“全部省份”；选择“地方法规”时显示省份；“中央 + 地方”时中央部分不按省份筛选，地方部分使用你选择的省份。

新建任务的检索框默认为空，不会预填示例词，也不显示示例占位文字。切换页面后会保留你实际输入和保存的草稿；旧版本遗留的单独“人工智能”产品默认值会迁移为空，多行草稿或其他自定义内容继续保留。

年份模式与省份各占一整行。年份区间请求早于当前检索实际存在的年份时，程序会读取网站提供的真实年份树，自动把起点提升到最早可用年份。任务详情同时显示“请求年份”和“实际年份”，原始请求不会从断点中丢失。若区间与真实年份完全无交集，程序会失败关闭，不会把空结果伪装成完成。

程序不再要求单独点击“预览（0 下载）”。点击“创建并开始”后，任务立即出现在右侧并进入“启动预检”，零下载核验在后台逐组合运行，界面持续显示已完成数和总数；核验结束后自动进入扫描。长时间年份核验不会阻塞任务列表、浏览器状态读取或停止操作。

预检期间可以点击“停止”。程序会设置取消标记，在安全边界结束当前检索，不再启动后续年份组合，并释放浏览器占用。预检阶段不显示“暂停”，因为此时尚未启动逐条下载工作线程。

修改运行中设置时，程序先停在安全边界，再以同一任务 ID 递增配置版本并从新的第 1 页扫描；已完成文件保留。

分页支持“扫描到尾页”和“指定页数上限”；达到上限但结果尚未结束时，任务会等待你选择“继续到尾页”或停止，不会把截断结果标记为完成。

## 批量采集

1. 批量选择“关键词”或“全文”；
2. 设置检索条件、目录格式和每页条数；
3. 点击唯一的“创建并开始批量采集”；
4. 每批最多 50 条；
5. 程序先取得网站原生 XLS，再在需要时生成“本地转换 XLSX”或“兼容 HTML-XLS”；
6. 程序调用 Word ZIP 并执行完整性校验；
7. 自动校验目录、ZIP CRC、数量、空文件、重复项和路径穿越；
8. 失败批次隔离，可在任务中心重试；
9. 批量扫描前和首批结果后会显示预计页数、政策数、50 条批次数和年度组合；
10. 规模达到阈值时必须人工确认，确认前不会创建或下载批次。

批量界面的匹配方式为“关键词”或“全文”，不会出现精确完整标题。关键词是“标题 + 精确”，全文是“全文 + 精确”，不会使用模糊匹配。

## 自适应低请求检索与采集边界

新任务的年份区间采用“先一次全部年份、再按需补年”的低请求策略：

- 每个关键词在每个子库只完整提交一次检索，中央和地方仍分别检索；
- 网站能一次给出全部结果时，程序直接翻页并在本地筛选年份；
- 结果超过网站可访问页数时，程序在当前结果页切换“公布年份”，只补尚未采全的年份，不重新输入关键词；
- 空年份自动跳过；同一政策去重后不会重复下载；
- 两次真正的结果操作之间至少间隔约 1 秒；人工完成验证码后额外等待约 10 秒再继续；
- 程序不会识别、破解或绕过验证码，出现验证码仍由使用者本人完成。

当单个年份或最细范围仍超过网站可访问上限时，任务进入
`CAPTURE_BOUNDARY_REACHED` 状态，显示已完成政策和剩余年份。
点击“继续完整补采”后，同一任务从断点继续处理剩余范围；“保留已完成结果并结束”则停止并保留当前成果。该状态不是失败，已完成文件不会丢失，也不会创建新任务或从头扫描。

## 验证码与自动恢复

- 程序不会识别、破解或绕过验证码，只检测人工操作结果；
- 验证码或登录页至少连续三次稳定消失，清除观察覆盖约 2.5 秒；页面、登录状态和选择器复核通过后，自动恢复最初触发等待的那个任务；
- 只恢复当前任务，不会因为浏览器已登录而启动其他任务；
- 同名版本、页数上限、批量规模和机构额度必须人工决策，不会自动继续；
- 网站覆盖层短暂残留时会继续观察，不会立刻结束工作线程；
- 复核遇到 `CAPTCHA_VISIBLE` 时回到观察状态，验证码再次清除后重新自动恢复；
- 自动恢复连续失败超过宽限期后，才显示唯一的“重新检测并继续”；点击后会重新积累三次稳定样本。
- `CAPTURE_BOUNDARY_REACHED` 是采集边界确认，不是验证码自动恢复，必须由使用者选择继续或保留结果。

## 一屏与滚动

- 1536×864 逻辑视口下，任务状态和浏览器左右同屏，应用外壳不出现外层上下滚动；
- 左侧保留进度、停止摘要、当前检索、断点和人工动作；停止详情可以在左侧内部滚动，应用外壳仍不滚动；
- 创建表单和任务设置使用固定操作栏，“创建并开始”或“应用设置”始终可见；
- 年份模式、年份范围、省份分别按稳定行显示，切换区间时不会挤压其他字段；
- 完整任务条目和长日志留在任务中心或展开详情中；
- 内置浏览器保留网页自身的上下、左右滚动和 50%–200% 缩放；
- 任务设置或停止详情打开时浏览器隐藏，关闭或应用后回到原位置。

## 数据与报告

1. 选择已经完成或部分完成的源任务；
2. 点击“生成数据包”；
3. 按来源和状态筛选逐条记录；
4. 可直接打开 Word、TXT、来源证据、CSV、XLSX 和任务报告；
5. 政府官网补全需要逐篇精确标题任务并显式勾选。

## 任务中心

- 按模式、状态和关键词筛选；
- 查看逐条状态、当前阶段和错误；
- 同名政策由使用者选择具体版本；
- 停止、继续和重试；
- 手动暂停、自动暂停、继续和停止；
- 年份、页数和组合断点；
- 任务多选、归档、回收站恢复和彻底删除；
- 查看批量断点；
- 打开任务输出目录和最新数据产物。

## 暂停、继续与完整原因

同一时刻只显示一个继续类主动作：

- 工作线程仍等待人工处理时显示“已处理，继续”；
- 工作线程已退出但存在可信断点时显示“从断点继续扫描”；
- 验证码自动恢复宽限期结束后显示“重新检测并继续”；
- 分页上限、批量规模和同名版本使用各自唯一决策按钮；
- `YEAR_FILTER_UNAVAILABLE`、年份区间无交集、页面结构硬停止等错误不会显示普通继续。

任务停止后，停止主因和“查看停止原因”按钮固定在运行面板上部，不需要双击或到页面底部寻找。单击按钮后，内置浏览器自动收起，弹窗显示用户可理解的主因、下一步、错误代码、当前检索组合与断点、可用年份或候选值以及原始错误详情。关闭弹窗后浏览器恢复到原位置。点击主动作后，顶部状态区会显示“正在处理”，并在结束前显示成功或失败。

## 设置与诊断

启动后端就绪后会自动预检，也可以手动重新诊断：

- Python 与 DrissionPage；
- SQLite 完整性；
- 数据和日志目录；
- 机构入口网络；
- 当前显示缩放；
- 内置/外部 Python 模式；
- 磁盘空间和依赖版本；
- 内置网页 50%–200% 缩放状态。

## 分页和规模确认

- 分页上限按每个检索组合独立计算；
- “继续到尾页”会为当前任务持久保存；
- 停止时保留当前年度、页码、已扫描页数和未扫描页数；
- 批量规模达到 20 页、500 条政策或 5 个批次时要求确认；
- 登录、额度、验证码、页面结构异常不会因普通“继续”被放行。

## 任务完成与设置修订

逐篇和批量任务正常完成后，程序自动退出当前任务详情并回到新任务创建
表单。关键词、年份、省份、匹配方式、每页条数和目录格式恢复为各自默认
值，输出目录使用程序默认路径。历史任务仍保留在任务中心，点击后可以
查看结果。失败、停止、部分完成和暂停任务不会自动复位。

暂停操作只暂停任务，不会自动打开任务设置。进入 `paused` 状态后，再手动
点击“任务设置”才能编辑。点击“保存修改”只生成设置修订预览，不立即重启
任务，随后提供两种处理方式：

- **保留已完成文件并重新扫描**：保留旧下载文件和已完成记录，清除旧
  扫描进度和分年计划，以同一任务编号和新配置版本从第 1 页重新扫描；
  已成功下载的同一政策不重复下载。
- **永久删除旧结果并重新扫描**：永久删除当前任务登记的下载文件、目录、
  批次和处理结果，立即释放磁盘空间；保留任务记录和配置历史，并按新
  配置重新扫描。

永久删除前会显示政策数量、文件数量、目录数量和预计释放空间，并要求
再次确认。只删除属于当前任务的登记文件；与其他任务共享的文件、输出
根目录、未登记文件和系统目录永远不会被删除。删除失败或受保护文件
存在时，任务保持暂停，新设置不会应用，也不会启动新扫描。

采集边界状态的次要按钮为“保留已完成结果并结束”。选择“继续完整补采”
时，同一任务从断点继续，只处理尚未完成的年份和省份。

## 数据保留

使用 `启动法宝工作台.cmd` 时，数据位于发布目录的 `数据` 文件夹。迁移或备份前先关闭应用，再复制整个 `数据` 文件夹。

## 0.2.4 版本说明

0.2.4 集中修正长时间预检期间的界面假死：

- 任务记录先创建并立即反馈，不再等待全部年份检索完成才返回；
- 后台预检按组合更新进度，任务中心可以正常刷新和查看；
- 预检停止会取消未开始的组合，并防止任务被重新标成运行状态；
- 浏览器租约在预检结束、失败或取消后释放；
- 批量采集与逐篇采集使用同一套后台预检行为。

## 本阶段不包含

- 单篇或批量下载的 WPS、PDF、纯文本、超文本、纯净版格式扩展；
- “保留字段信息”“保留本篇右侧的法宝联想”“保留正文中的法宝联想”三个选项；
- macOS 版本；
- 自动识别或绕过验证码。
