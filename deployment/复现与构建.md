# 复现与构建（0.2.4）

## 源码环境

- Windows 10/11 x64；
- Node.js 24；
- pnpm；
- Python 3.14.7 x64；
- Edge 不需要参与运行。

## 安装开发依赖

```powershell
pnpm install --frozen-lockfile
python -m venv .packaging-venv
.packaging-venv\Scripts\python.exe -m pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple -r engine\requirements-lock.txt
```

## 测试

```powershell
pnpm test
pnpm test:python:coverage
pnpm test:node:coverage
pnpm --dir apps/desktop typecheck
pnpm --dir apps/desktop build
pnpm --dir apps/desktop smoke:stage2
pnpm --dir apps/desktop smoke:stage3
pnpm --dir apps/desktop smoke:stage4
pnpm --dir apps/desktop smoke:stage5
pnpm --dir apps/desktop smoke:stage6
```

## 构建便携包

```powershell
pnpm build:portable
pnpm package:source
pnpm verify:portable
```

输出：

- `release/PkulawWorkbench-portable/`：免安装目录；
- `outputs/北大法宝采集器_Windows便携版_<版本>_<日期>.zip`；
- 同名 `.sha256` 文件。
- `outputs/北大法宝采集器_源码与构建脚本_<日期>.zip`；
- 源码包同名 `.sha256` 文件。

本地夹具通过不等于真实站点通过。发布记录必须把“本地自动化通过”和“真实校园网络人工验收”分开列示。

发布包验证应同时检查版本元数据、内置 Python 后端版本、
SQLite schema v6、ZIP SHA-256、首次启动、一键启动器、
