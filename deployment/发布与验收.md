# 0.2.2 发布与验收

## 发布边界

- 本地自动化夹具通过，不等于真实校园网络通过；
- 真实站点只执行用户明确同意的小规模、人工监督验证；
- 不执行真实尾页大批量下载；
- 不绕过登录、滑块、验证码或机构额度；
- 不保存账号密码，不导出 Cookie；
- 正常运行不依赖 Agent、Codex 或在线大模型。

## 本地发布门禁

- Python 单元、协议和存储测试；
- TypeScript 类型检查；
- Vitest；
- Electron 生产构建；
- 阶段 2、3、4、5、6 烟测；
- SQLite schema v6 和 integrity_check；
- Word、TXT、CSV、XLSX、官方 HTML、截图、报告和 SHA-256 一致；
- 中文、空格、长路径和无效输出目录；
- 高 DPI、断网、Python 崩溃、强制退出和重启恢复；
- 一键启动器、内置 Python、无 Electron/Python 残留；
- 发布包版本信息、依赖锁和 ZIP SHA-256。
- 0 下载预览、网页缩放和统一验证码状态；
- 原生 XLS、派生 XLSX、兼容 HTML-XLS 与 Word ZIP 契约；
- 内置 antiword、正文完整性和 SQLite v6 来源模型。

## 真实站点待验收

以下项目必须与夹具结果分开记录：

- 目标学校代理跨域后的同一标签绑定；
- IP 登录或学校账号登录；
- 真实 V6 搜索和适配诊断；
- “碳中和”正式全范围逐篇关键词和批量关键词任务；
- 真实 Word 下载、批量原生 XLS 和 Word ZIP；
- 真实尾页、分页上限和“继续到尾页”；
- 真实批量规模确认；
- 数据处理、来源证据、SHA-256 和额度风险提示。

真实多年度、尾页批量下载和批量 ZIP 不得在没有单独授权时执行。
