# 法宝工作台 0.2.4 快速开始

## 启动

双击 `启动法宝工作台.cmd`。

启动器会把数据保存在发布目录下的 `数据` 文件夹，不需要安装 Python，也不会启动外部 Edge。

请使用 `启动法宝工作台.cmd`。启动器会在 Electron 进程启动前分配随机回环调试端口，并把数据目录指向当前发布目录。不要绕过启动器直接双击 `法宝工作台.exe`。

## 首次使用

1. 在“总览”顶部填写机构名称和授权入口并保存；
2. 在总览右侧内置浏览器完成 IP、CARSI 或账号登录；
3. 如果出现滑块或验证码，由使用者本人完成；
4. 登录后浏览器自动收起，打开“设置与诊断”运行启动预检；
5. 进入“逐篇采集”或“批量采集”，设置条件后直接点击“创建并开始”；
6. 任务运行时，左侧查看状态，右侧浏览器处理登录、验证码和同名版本；
7. 运行中需要改条件时打开“任务设置”；应用后使用同一任务 ID 从前一版本的安全边界切换；
8. 在“任务中心”查看逐条状态，执行暂停、继续、停止、断点恢复、归档或回收站操作；
9. 在“数据与报告”生成 TXT、总目录和来源验收报告。

## 新增操作

- 年份支持全部年份、指定年份和区间；单年与区间可手输 1949 至当前年份；
- 单篇可选“关键词”“全文”“精确完整标题”；它们分别对应
  `标题 + 精确`、`全文 + 精确`、`标题 + 精确`，只有精确完整标题会要求同名候选选择；
- 批量可选“关键词”或“全文”，分别对应 `标题 + 精确` 和 `全文 + 精确`；
- 新建任务检索框为空，不预填示例关键词；切换页面后保留实际草稿；
- 中央法规隐藏省份项；地方法规显示省份；中央+地方只对地方子库应用省份；
- 年份和省份各占一行；请求年份早于网站真实可用年份时，程序自动从最早可用年份开始，并在详情中显示请求区间与实际区间；
- 单篇和批量检索草稿在页面切换后保留；
- 不再需要单独预览；“创建并开始”内部先做零下载检前核验；
- 点击开始后任务立即出现在任务区；检前核验在后台运行并显示已完成组合数，
  不再因为长时间核验而显示“暂无任务”或锁住任务列表；
- 检前核验期间可以停止任务；停止后会取消后续年份组合并释放浏览器占用；
- 分页支持扫描到尾页或指定上限；
- 达到页数上限时，必须选择“继续到尾页”或停止；
- 批量任务预计规模较大时，需要二次确认；
- 普通删除先进入回收站，活动任务不能归档或永久删除；
- 永久删除可选择保留输出文件，或将数据库登记文件移入 Windows 回收站；
- 内置网页支持 50%–200% 缩放，快捷键为 `Ctrl +`、`Ctrl -`、`Ctrl 0`；
- 验证码至少连续三次稳定消失、覆盖约 2.5 秒后自动恢复原任务；短暂残留继续观察；
- 自动恢复失败超过宽限期后才显示唯一的“重新检测并继续”；
- 同一时刻只显示一个继续类主动作；停止主因固定在面板上部，单击“查看停止原因”即可打开完整详情；
- 1536×864 逻辑视口下任务区与浏览器左右同屏，外层页面不上下滚动；
- 打开任务设置或停止详情时浏览器收起，关闭或应用后恢复；
- 验证码打断设置时保留未提交草稿，处理后可以重新打开继续编辑。

## 安全边界

- 程序不保存账号密码；
- 程序不导出 Cookie；
- 程序不识别、外送或绕过验证码；
- 程序不绕过登录、额度或校园权限；
- 宽泛关键词模式不会自动回退政府官网；
- 只有逐篇精确标题且明确 `NO_EXACT_MATCH` 时，用户才可开启官方补全；
- 政府官网正文整理件不会冒充原生附件。
- 本阶段仍不包含 WPS、PDF、纯文本、超文本、纯净版扩展下载，也不包含三个法宝联想保留选项。

## 当前验收范围

本地夹具、打包、首次启动、诊断、崩溃恢复、中文/空格长路径、来源治理和文件一致性已通过自动验证。

真实北大法宝尾页、上限确认、规模确认、学校登录细节和一条真实 Word 下载仍需在目标校园网络中进行小规模、人工监督验收。

## 0.2.4 修复重点

- 长时间年份预检不再阻塞任务列表、浏览器状态和停止操作；
- 任务创建后立即显示“启动预检”，并持续更新已完成组合数和总组合数；
- 预检阶段只提供“停止”，不显示此时无效的“暂停”；
- 用户停止预检后，后台组合会尽快退出，不会被重新恢复成运行或等待状态。
