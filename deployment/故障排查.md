# 故障排查（0.2.2）

## 应用无法启动

1. 确认 Windows 10/11 x64；
2. 确认发布包已完整解压，不要在 ZIP 内直接运行；
3. 检查 `resources/engine/pkulaw-engine.exe` 是否存在；
4. 打开 `数据/logs/desktop.jsonl` 和 `engine.jsonl`；
5. 若 Windows 提示未知发布者，这是当前未签名便携版的预期提示，应由团队管理员确认来源和 SHA-256 后再运行。

## Python 后端未连接

打开“设置与诊断”：

- 若显示“应用内置”，不需要安装 Python；
- 若显示“源码 Python”，当前是开发模式；
- 查看后端 PID、协议版本和最近日志；
- 点击“重启后端”；
- 若出现“自动恢复”，等待一次自动重连。

## 机构入口无法访问

- 先连接学校 VPN；
- 打开内置浏览器重新加载机构入口；
- 检查诊断中的网络结果；
- HTTP 403 通常表示当前网络出口或权限不符合学校要求；
- 不要通过高频刷新或绕过登录解决权限问题。

## 登录、滑块或验证码

- 由使用者本人在内置浏览器操作；
- 完成后点击“已处理，继续”；
- 程序不会自动识别、外送或绕过验证码；
- 登录失效、额度耗尽不会触发政府官网回退。

## 同名政策

任务中心会列出同名候选。请核对标题、机关、公布日期、文号和时效性后选择。程序不会默认选择第一条。

## 任务一直显示“正在暂停”或“正在停止”

- 程序会等待当前检索、详情读取、Word、目录或 ZIP 下载与校验完成；
- 不要强制结束正在下载或写入文件的步骤；
- 若等待明显异常，保留日志，并确认浏览器页面是否仍在加载；
- 重启后残留活动任务会被标记为 `APPLICATION_INTERRUPTED`，恢复前重新检查断点。

## 分页上限或批量规模确认

- `PAGE_LIMIT_REACHED`：选择“继续到尾页”或停止；
- `BATCH_SCALE_CONFIRMATION_REQUIRED`：核对页数、政策数和批次数后确认；
- 普通“已处理，继续”不能绕过这两个门禁；
- 登录、额度、验证码和页面结构异常也不会触发政府官网回退。

## SQLite 升级

- 旧库首次迁移前会自动在线备份为 `pkulaw.sqlite3.pre-v6-<时间>.bak`；
- 迁移后 schema 为 v6；
- 若数据库损坏，先关闭应用，保留主库、`-wal`、`-shm` 和备份文件，再按数据恢复文档处理。

## 输出目录不可写

- 点击输出目录旁的“浏览”重新选择；
- 避免选择程序目录、系统目录或只读网络盘；
- 中文和空格目录受支持；
- 若目标不是目录或没有写权限，应用会在任务创建前拒绝。

## Word 正文提取失败

- DOCX 使用 python-docx；
- 旧版 DOC 优先使用发布包内置的离线 antiword；
- 内置转换器缺失、损坏或版本不符时会失败关闭，并显示明确错误；
- 正文过短或疑似截断时，该条会进入“待核验”；
- 不要把 HTML 错页或损坏 Word 当作成功。

## 政府官网补全失败

政府官网补全只适用于逐篇精确标题任务，且北大法宝必须明确无精确匹配。

截图或 HTML 证据失败时，该条进入待核验。不要删除来源证据后再把记录改成成功。

## 应用异常关闭

- 已提交的任务状态保存在 SQLite；
- 重新启动后打开任务中心；
- 失败项和停止任务按界面提示恢复；
- 应用通过标准输入管道管理 Python 生命周期；Electron 退出后 Python 会收到 EOF 并停止。
