## 本轮发现并修复的真实缺陷

1. 空精确标题结果页没有筛选、页大小或“不分组”控件时，
   原程序误报 `RESULT_GROUPING_UNAVAILABLE`。现改为仅对已验证的
   精确标题 0 结果跳过不适用控件，其他非空页面仍强制完整门禁。
2. 尾页“下一页”所在父级 `li.disabled` 未被完整读取，
   导致尾页误判为可继续翻页。现同时检查控件、父项和 ARIA 禁用状态。
3. 真实政府官网搜索需要解析 360 桌面结果的 `data-mdurl` 和跳转参数。
   现支持明确跳转解包，并在真实模式强制最终域名为政府域名；
   本地夹具仍要求官方标记且标题完全一致。
4. 无独立“精确”控件的夹具 profile 应采用检索字段门禁；
   结果页隐藏下拉框需按选项值切换标题/全文，不能只读取当前值。
5. 子库切换在结果页未实际点击可见库链接。现切换到目标库，
   连续两次核验可见库和全部隐藏 `Library` 字段。
6. 批量下载子页和 Word COM 后台线程问题沿用本阶段修复：
   BatchDownload 子页清理、`CoInitialize/CoUninitialize`、
   `Content.Text` 失败时使用 `SaveAs2` UTF-8 回退。
