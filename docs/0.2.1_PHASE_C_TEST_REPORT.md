## 完成内容

### 全局浏览器租约

- 新增 `engine/pkulaw_engine/browser_lease.py`；
- 租约包含 `leaseId`、`taskId`、`mode`、`createdAt` 和 `updatedAt`；
- 任意时刻最多一个逐篇、批量或浏览器型数据处理任务持有内置浏览器；
- 同一任务、同一模式重复获取返回原租约，不产生第二个租约；
- 不同任务或不同模式获取租约返回 `BROWSER_LEASE_BUSY`；
- 释放和校验均核对 `leaseId`，错误所有者不能释放或冒用他人租约；
- 租约只存在于 Python 进程内存，Python 重启后不会恢复旧租约。

### 应用层启动门禁

- `EngineApplication` 在工作线程启动前原子取得租约；
- 启动参数校验、任务配置解析或线程创建失败时立即释放已取得租约；
- 单篇、批量和浏览器型数据处理共用同一租约；
- 纯本地数据处理不占用浏览器租约；
- 租约忙碌错误包含当前持有任务和模式；
- 应用退出时停止活动线程并清除进程内租约；
- 应用重启仍按既有逻辑把残留活动任务标记为 `APPLICATION_INTERRUPTED`。

### 启动幂等

- `task.create` 支持请求级 `operationId`；
- 同一 `operationId` 和相同请求只返回原任务，不再次写入 SQLite；
- 同一 `operationId` 被用于不同创建请求时返回 `IDEMPOTENCY_KEY_REUSED`；
- 同一任务重复启动返回当前任务详情，不创建第二个工作线程；
- 已完成、暂停、等待人工或运行中的任务重复调用启动不会重新执行；
- 单篇、批量启动、恢复、重试和浏览器型数据处理均接入请求级幂等键；
- 逐篇和批量表单增加同步双击锁，防止 React 重绘前的第二个点击再次创建任务。

### 状态与界面

- `browser.state` 返回 `lease` 字段；
- 新增 `browser.lease` 只读查询方法；
- 新增 `browser.lease-acquired` 和 `browser.lease-released` 事件；
- `BrowserHostState` 新增 `browserLease`；
- BrowserHost 在租约事件到达时同步更新 Electron 状态；
- 内置浏览器页显示租约是否空闲、持有任务和模式；
- 逐篇采集、批量采集和任务中心显示租约提示；
- 租约被其他任务占用时，新采集启动按钮禁用；
- 精确标题政府官网补全需要浏览器时，数据处理启动按钮按租约状态禁用；
- 设置与诊断页显示当前租约所有者。
