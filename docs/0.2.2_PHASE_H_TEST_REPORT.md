## 进程与安全

- 应用正常退出、启动器退出和强制退出测试后无 Electron/Python 进程；
- 便携 ZIP 不含 `数据`、SQLite、日志、运行时、测试目录或开发缓存；
- 便携 ZIP 只有 DrissionPage 自带 Cookie `.pyi` 类型存根，
  不含真实 Cookie 数据；
- 源码包不含运行数据、日志、输出、release、clean-room、覆盖数据或 Node 依赖；
- 未保存账号密码，未导出 Cookie；
- 未访问真实北大法宝。

最终源码包验证同时确认：

- ZIP 内不包含 `outputs/`、`release/`、`build/`、`clean-room/`、
  `runtime/`、`node_modules/`、SQLite、日志、覆盖数据和开发缓存；
- 必需源码、测试、脱敏夹具、锁文件、构建脚本和部署文档存在；
- 源码 ZIP 与 `.sha256` 侧车文件可独立复算一致；
- ZIP 内不包含源码包最终哈希，避免源码包自引用。
