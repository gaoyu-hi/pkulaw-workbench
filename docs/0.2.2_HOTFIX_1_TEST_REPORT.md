## 修复内容

1. 真实结果页的 `did-finish-load` 早于动态结果列表稳定时，选择器诊断不再
   立即失败并缓存错误状态。

   最长等待 5 秒；搜索页、详情页和真实缺失仍按原规则立即失败。
3. 单篇和批量生产表单移除夹具预填值，关键词草稿、年份和其他检索条件写入
   本机存储，切页返回后恢复。
4. 年份从下拉选择改为可键盘输入的四位年份；范围和后端校验统一为
   1949 至当前年份。
