## 暂停和继续

手动暂停：

- 接口立即写入 `pausing`；
- 当前动作完成后转为 `paused`；
- checkpoint 保存 `pauseKind=manual`、暂停原因、暂停阶段和当前动作；
- 暂停期间不再发起新的检索、翻页、详情或下载请求。

手动继续：

- 使用 `single.resume`；
- 先核验 Python 页面绑定；
- 再核验登录、滑块和选择器 profile；
- 校验失败时任务保持暂停；
- 成功后从当前安全边界继续，不重新执行整个关键词检索。

自动暂停：

- 登录失效使用 `waiting_login`；
- 滑块、页面不稳定和同名候选使用 `waiting_manual`；
- 使用原有 `single.continue` / “已处理，继续”；
- 同名候选项必须通过候选选择接口处理，普通继续会被拒绝。

停止：

- 接口立即写入 `stopping`；
- 当前安全步骤结束后转为 `stopped`；
- 已完成文件、任务项和 checkpoint 保留；
- 重复停止不重复发出控制。

## 异常恢复

Engine 启动时扫描残留活动状态：

```text
preflight
running
waiting_login
waiting_manual
verifying
pausing
paused
stopping
```

统一转为：

```text
status = stopped
error.code = APPLICATION_INTERRUPTED
currentStage = application-interrupted
```

原 checkpoint 保留，并增加：

- `interrupted=true`
- `interruptedPreviousStatus`
- `interruptedAt`
