## 1. 调整原则

“全量”继续表示检索范围全量，不再表示每一条命中政策都必须真实下载。

- 必须对正式查询“碳中和”的中央 + 地方、全部年份、每页 100、不分组结果
  扫描到真实尾页；
- 必须验证结果数、年份分区、页码、SearchSession、结果签名和尾页；
- 真实 Word、目录和 ZIP 下载使用预先固定的分层样本；
- 未被抽中的政策明确记为
  `OUT_OF_SCOPE_BY_SAMPLING_ACCEPTANCE`，不得记为成功、失败或已下载；
- 抽样结果只能证明所覆盖的风险类别和真实站点链路，不得写成“全部唯一政策
  均已下载或逐篇核验”。

本次调整的目的，是避免以重复下载近两万篇文件代替对检索、分页、详情差异、
旧 DOC、目录格式、ZIP、原子发布、恢复和来源一致性的有效覆盖。

## 2. 全量检索基线

正式碳中和任务的检索基线固定为：

- 关键词：`碳中和`；
- 匹配方式：关键词；
- 子库：中央 + 地方；
- 年份：全部年份；
- 每页：100；
- 分组：不分组；
- 分页：扫描到真实尾页。

当前已完成的只读扫描结果为：

- 唯一任务项：`19,040`；
- 中央：`1,838`；
- 地方：`17,202`；
- 结果分区：`111`；
- 所有分区必须持续通过 SearchSession、页码、结果数和结果签名校验。

后续不得用窄查询替代这组全量扫描证据。

## 3. I-S 逐篇 Word 样本

### 3.1 已知执行样本

原严格执行任务
`a8f74e28-e2a9-43fe-89cd-0076e5bf728a` 在调整标准后安全停止：

- 完成真实 Word 下载与基础校验：`2,784`；
- 证据支持的失败：`3`；
- 未执行：`16,253`。

这 `2,784` 条作为超额真实样本保留，不重复下载；未执行的 `16,253` 条不构成
样本失败。

### 3.2 固定补充样本

在正式停止点之后，从全量任务中预先选择一个固定清单：

- 地方库 2008–2020 每个年份至少 1 条唯一标题；
- 地方库 2021–2024 每个年份选择 3 条，覆盖华东、华中/中原、西部三个
  风险组；
- 共计 25 条唯一稳定政策 ID；
- 清单生成后计算 SHA-256，执行过程中不得因为结果不理想而替换；
- 若某项因真实站点临时故障失败，保留失败证据，可在同一 ID 上重试，但不能
  用另一篇静默替换。

每一条补充样本必须满足：

- 真实打开详情并点击 Word；
- 文件后缀、OLE/ZIP 文件签名和 intent 一致；
- 文件 SHA-256、SQLite 任务项和来源 URL 一致；
- 详情标题与稳定政策 ID 一致；
- 正文完整性状态为 `complete`，或保留明确的可解释失败；
- 不得存在 `DOWNLOAD_UNCLEAR`、空正文伪成功或计划外下载。

验收门槛：

- 25 条全部进入终态，不能留下未尝试项；
- 至少 20 条完成 Word 下载并通过校验；
- 其余至多 5 条只能由可复现的站方不可用、附件型正文或其他证据充分的
  环境/来源限制导致；
- 若同一种代码缺陷导致 2 条以上失败，必须先修复并重新执行受影响样本。

### 3.3 正文与格式覆盖

补充样本之外，现有真实证据必须继续覆盖：

- 普通 HTML 正文；
- 章节 + 条文结构；
- 目录和标题高亮导致的换行；
- 表格；
- 附件型/无 HTML 正文；
- 详情页不可用；
- `.doc` OLE 签名；
- `.docx` ZIP/OOXML 签名；若站点本次只返回一种格式，记录另一种未返回。

## 4. I-B 批量样本

批量模式不要求下载全部约 381 个 50 条批次，但必须使用独立任务和真实
“碳中和”结果，覆盖：

- 中央库批次；
- 地方库批次；
- 中央 + 地方组合；
- 单条批次；
- 少于 50 条批次；
- 正好 50 条批次；
- 原生 BIFF `.xls`；
- 从原生 XLS 派生的 XLSX；
- 兼容 HTML-XLS；
- Word ZIP。

每个批次必须验证：

- SearchSession、页码、行起止序号、稳定政策 ID、标题和勾选数量；
- 目录下载 intent、downloadId、实际格式和来源；
- 目录校验完成后才能启动 ZIP；
- ZIP CRC、成员数、空文件、重复项、路径穿越和稳定 ID 映射；
- 批次目录、ZIP、报告、SQLite、来源证据和 SHA-256 一致；
- 失败批次隔离，不重复已完成批次。

已有 I-3、I-4、I-5、I-6 的真实结果可以作为整体覆盖证据；最终构建仍需至少
执行一个新的“碳中和”真实小批量任务，证明当前构建没有回归。

## 5. 数据处理样本

数据处理验收范围：

- 原 I-7 的 2,784 个已下载成功项；
- 新补充的 I-S 固定样本；
- 新 I-B 小批量样本；
- I-1 至 I-6 已有真实产物。

必须生成并核验 TXT、CSV、XLSX、报告、来源网址、检索时间、抓取方式、
来源类型、正文来源、转换器名称/版本、正文完整性、核验状态和 SHA-256。

未下载的 16,253 条不得生成伪造 TXT，也不得出现在“已处理成功”统计中。

- 不得声称“全部 19,040 篇政策已下载并逐篇验收”。
