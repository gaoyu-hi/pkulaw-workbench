# 法宝工作台 macOS（Apple 芯片）版 · 团队使用手册

- **版本**：0.2.4
- **适用机器**：Apple 芯片 Mac（M1 / M2 / M3 / M4）
- **系统要求**：macOS 13（Ventura）及以上
- **构建日期**：2026-11-06
- **发布状态**：未签名测试包（团队内部分发用，非 App Store）

---

## 1. 这是什么

「法宝工作台」是北大法宝文献检索与批量下载的桌面工具。本版本为 macOS Apple 芯片移植版，功能与 Windows 0.2.4 对齐，界面为 Electron 应用，内置独立 Python 后端与内置浏览器。

## 3. 安装

1. 双击 `.dmg` 挂载；
2. 把「法宝工作台.app」拖到「应用程序」文件夹；
3. 弹出安装卷（右键桌面上的安装盘 → 推出）。

### 首次打开（绕过系统安全拦截）

本包未签名，macOS 会拦一下。**务必右键打开，不要双击**：

1. 打开「应用程序」，找到「法宝工作台」；
2. **按住 Control 点击**（或右键）→ 选「打开」；
3. 弹窗点「打开」。

> 若仍被拦：系统设置 → 隐私与安全性 → 拉到最下面，点「仍要打开」。
> 绕过一次后，以后双击即可正常启动。

## 4. 首次启动

- 启动后主界面状态栏应显示「应用内置」，说明内置 Python 后端已就绪；
- 首次启动会在系统用户目录下自动新建数据目录（不会写进 app 内部）；
- 若提示无 arm64 Python 后端等错误，说明安装不完整，重装 DMG。

## 5. 登录与验证码（必须本人完成）

- 用**机构账号**登录北大法宝；
- 验证码/滑块需**人工完成**，程序不会自动破解；
- 程序不保存账号密码，不导出 Cookie。

## 6. 任务流程

- **逐篇下载**：检索 → 勾选 → 单篇任务；
- **批量下载**：检索结果页点「批量下载」→ 确认范围；
- 任务进度、断点可恢复（见第 8 节）。

## 7. 旧版 Word（.doc）转换

macOS 版用系统自带 `textutil` 转换旧版 `.doc`，无需额外安装。转换来源与正文会记录进数据库，可追溯。

## 8. 异常处理

- **强制退出后恢复**：任务与断点存在 SQLite 中，重启后可在任务列表恢复；
- **进程残留**：正常退出会清理 Electron 与后端进程；若异常退出导致残留，重启应用或注销系统即可。

## 9. 未签名说明（重要）

- 本包为**未签名测试包**，只适合**团队内部测试使用**；
- 首次打开需右键绕过（见第 3 节）；
- **不可**作为对外正式发布版本。正式分发需 Apple Developer Program 签名与公证（另行安排）。

## 10. 数据与账号边界

- 每个成员用**自己的机构账号**登录，不要共用一个账号（会触发风控/超额）；
- 数据目录独立，**不要从 Windows 版本直接拷贝** Cookie、Session 或含旧路径的数据库；
- 下载成果默认落在任务指定的输出目录，请注意机构下载额度。
