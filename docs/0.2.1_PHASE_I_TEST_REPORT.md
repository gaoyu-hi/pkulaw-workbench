## 完成内容

### 统一任务呈现

- 新增 `apps/desktop/src/renderer/src/task-presentation.ts`；
- 任务状态、阶段、按钮动作、暂停原因、错误恢复、下载意图和
  SHA-256 文案集中维护；
- 逐篇、批量、数据处理、任务中心和总览使用同一状态词汇；
- 任务状态包括 pending、preflight、waiting_login、running、
  waiting_manual、verifying、pausing、paused、stopping、completed、
  partial、stopped 和 failed；
- 工作流阶段条覆盖：
  - 浏览器绑定与登录；
  - 验证新检索；
  - 应用年份、省份、时效性筛选；
  - 验证页大小；
  - 切换不分组；
  - 选择批次；
  - 校验目录；
  - 校验 ZIP；
  - 原子发布；
  - SQLite 登记；
  - 逐篇详情、Word 下载和最终登记。

### 检索身份与下载意图

- 检索身份卡显示实际查询、匹配方式、子库、年份、省份、时效性、
  当前页、总页数、实际页大小、分组模式、结果数、当前页行数、
  searchId 和完整结果签名；
- 下载意图卡显示：
  - intentId；
  - downloadId；
  - Word、批量目录、Word ZIP 或政府官网附件类型；
  - pending、started、completed、validated、validation_failed、failed；
  - 已消费次数和最大次数；
  - 预期后缀、来源主机、临时路径；
- `wait_for_download_intent()` 增加进度回调；
- 单篇、批量和政府官网附件在 started/completed/failed 时同步 checkpoint；
- 不匹配下载事件通过 `DOWNLOAD_EVENT_MISMATCH` 转发到渲染层；
- 无关下载只显示告警，不改为当前任务成功或失败。

### 浏览器租约

- BrowserHost、逐篇、批量、任务中心和设置页统一使用租约卡；
- 显示租约持有任务、模式、leaseId、创建时间和更新时间；
- 租约忙碌时启动按钮禁用，并显示具体持有任务；
- 租约未知、空闲和占用状态均明确显示，不猜测可用。

### 暂停与恢复

- 手动暂停和自动暂停使用不同标题与说明；
- 自动暂停细分：
  - 机构登录；
  - 滑块或验证码；
  - 页面选择器/结构调整；
  - 同名候选选择；
  - 分页上限；
  - 批量规模确认；
- 机构额度异常和页面结构异常标记为硬停止；
- 硬停止不会通过普通“已处理，继续”放行；
- 分页上限继续到尾页和批量规模确认继续使用显式按钮；
- 用户主动停止不再被错误显示为普通执行失败。

### 错误卡与时间线

- 错误卡显示错误码、用户原因、失败阶段、已完成数、当前断点、
  恢复建议、允许动作和硬停止标记；
- 覆盖：
  - SearchSession 身份；
  - 筛选；
  - 页大小；
  - 分组；
  - 选择器；
  - 下载意图；
  - Word 校验；
  - 批次文件完整性；
  - 登录、额度、应用中断；
- SQLite `task_events` 新增只读列表，详情返回最近 200 条任务事件；
- 每个 `task.updated` 事件保存更新后的有效状态、阶段、动作、
  错误、暂停原因和检索摘要；
- 时间线折叠连续相同状态；
- 2 秒内短暂 `running -> waiting_manual -> running` 抖动
  不生成重复记录；
- 低层任务项和批次逐项更新不进入高层阶段时间线。

### 数据、报告与诊断

- 数据页增加来源筛选、待核验筛选和 SHA-256 状态筛选；
- SHA-256 状态区分完整、缺失和不一致；
- Word、TXT、证据、artifact 和批次路径可展开查看；
- 长路径、长错误和长签名可通过 Electron clipboard API 复制；
- 设置页显示：
  - 应用、Python、后端和协议版本；
  - Electron、Chromium 和 Node 版本；
  - SQLite 路径、schema/期望版本和 integrity；
  - 浏览器 View、目标绑定、Session、认证和选择器状态；
  - 数据、数据库、日志、下载临时和系统临时目录；
  - 数据、日志、下载临时和系统临时目录可写检查；
  - 最近失败任务的阶段和恢复建议；
- 诊断缺失时显示“未检测/未知/未通过”，不推断成功。

### 高 DPI 与窄窗口

- 主窗口最小宽度由 1120 调整为 860；
- 新增 900px 以下响应式导航、单列任务/数据/设置布局；
- 866px 内部宽度和 125% 缩放验证：
