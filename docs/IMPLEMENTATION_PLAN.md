# 北大法宝采集器实施计划

## 权威依据

产品设计以以下文件为准：

- `outputs/北大法宝政策采集GUI改进方案_V3_Electron内置浏览器与Python后端_2026-10-31.md`

技术探针证明 V3 的关键连接方式可行：

- Electron 创建可见 `WebContentsView`；
- Electron 进程启动前注入随机本机调试端口；
- Python/DrissionPage 自动连接该端口；
- DrissionPage 能读取和修改内置网页；
- Electron session 接管下载并把完成文件交回 Python；
- 应用内新窗口可作为新的 `WebContentsView` 被 DrissionPage 发现；
- 持久 session 分区能保留 Cookie。

## 阶段门禁

每个阶段必须：

1. 只完成本阶段范围；
2. 运行对应测试；
3. 更新 `PROJECT_STATE.md`；
4. 写本阶段测试记录；
5. 生成下一阶段提示；
6. 经用户确认后再进入下一阶段。

## 阶段 1：正式应用骨架

目标：

- 建立可运行的 Electron + React + TypeScript 主应用；
- 建立 Python 后端进程；
- 建立 JSON 行协议与协议版本握手；
- 建立本地 SQLite 初始任务模型；
- 建立统一日志和测试入口；
- 不接入真实北大法宝业务。

验收：

- Electron 窗口可启动；
- React 页面可显示；
- Python 子进程可启动和退出；
- 双向请求、事件和错误消息可测试；
- 应用退出后无残留子进程；
- 单元测试通过。

## 阶段 2：内置浏览器、登录和下载基础设施

目标：

- 主进程创建和管理 `WebContentsView`；
- 随机本机调试端点自动建立；
- DrissionPage 自动连接；
- 内嵌浏览器工具栏；
- 机构 session 分区；
- 人工登录和滑块状态；
- 下载接管、临时文件、完成事件和失败事件；
- 新窗口拦截；
- 页面和 Python 崩溃恢复基础。

验收：

- 页面完全显示在应用内；
- 不使用外部 Edge；
- 用户不需要输入端口；
- 下载文件归属正确；
- 新窗口不逃逸；
- session 可跨重启恢复；
- 页面或 Python 故障不会伪造任务成功。

## 阶段 3：逐篇采集迁移

目标：

- 迁移检索、中央/地方子库、年份、省份和时效性；
- 迁移分页、详情和政策元数据；
- 迁移 Word 下载；
- 迁移同名消歧；
- 统一逐条断点；
- 接入机构额度与人工验证保护。

验收：

- 可用受控样例完成一条 Word 采集；
- 同名多版本不会默认选择第一条；
- 停止后可以精确恢复；
- 下载、文件落盘和目录状态一致；
- 机构额度或登录失效会硬停止；
- 不使用 Agent 完成运行。

## 阶段 4：批量采集迁移

目标：

- 迁移每页检索和每批最多 50 条；
- 迁移网站原生目录和 Word ZIP；
- 迁移 Excel/XLS/HTML-XLS 校验；
- 迁移 ZIP CRC、数量、空文件和重复项校验；
- 迁移批次断点；
- 建立批次恢复和逐条身份映射。

验收：

- 可用受控样例完成一个小批次；
- 未通过校验的批次不会标记完成；
- 单个批次失败不破坏已验收批次；
- 重启后从准确批次恢复；
- ZIP 和目录的身份映射可审计。

## 阶段 5：正文、目录与来源治理

目标：

- 每条政策生成 TXT；
- 生成总目录 CSV/Excel；
- 保存来源网址、检索时间、抓取方式和来源类型；
- 保存页面证据和文件哈希；
- 接入政府官网精确标题补全；
- 明确“政府官网正文整理”来源；
- 生成任务报告。

验收：

- Word、TXT、总目录和来源证据齐全；
- 宽泛关键词不自动回退政府官网；
- 登录、额度和验证码问题不触发回退；
- 政府官网整理件不会冒充原生附件；
- CSV、Excel 和 SQLite 状态一致。

## 阶段 6：界面、稳定性与团队交付

目标：

- 完成任务中心、筛选、重试和报告界面；
- 完成设置与诊断；
- 完成完整自动化测试；
- 完成 Windows 安装程序；
- 完成一键启动器；
- 完成依赖说明、使用手册、故障排查和复现文档；
- 在干净 Windows 环境验证。

验收：

- 目标团队电脑无需安装 Python；
- 无需 Agent 运行；
- 第一安装、首次登录、两种采集模式均通过；
- 长路径、高 DPI、断网、崩溃和重启测试通过；
- 部署包、源码、测试记录和文档齐全。
