## 完成内容

### SearchSession 与 SearchTransaction

- 新增 `engine/pkulaw_engine/sources/search_transaction.py`；
- `SearchRequestIdentity` 保存查询、匹配方式、子库、年份、省份、时效性和请求页大小；
- 每次新检索生成独立 `searchId`；
- `SearchSession` 包含查询、匹配方式、子库、年份、省份、时效性、请求/实际页大小、当前页、总页数、结果数、行数、分组模式、结果签名、观察时间和 URL；
- `SearchTransaction` 要求连续两个采样点身份一致；
- `SearchSession` 可序列化到指定 checkpoint 和从 checkpoint 恢复；
- 旧任务 checkpoint 缺少 `SearchSession` 时通过 `checkpoint_requires_controlled_research()` 判断必须重新检索。

### 提交前门禁

- 提交前确认目标子库导航已经处于目标状态；
- 同时校验可读取的 `Library` 隐藏字段；
- 输入关键词、匹配方式和检索字段；
- 标题模式要求 `SearchKeywordType=Title`；
- 关键词模式要求 `SearchKeywordType` 为 `FullText`、`Keyword` 或 `Content`；
- 检索字段无法切换时拒绝提交，不猜测；
- 提交前记录旧 URL、页码、结果数、结果身份、页大小、分组模式和一次性 DOM 标记；
- 旧结果容器存在时插入唯一、不可见的检索事务标记。

### 提交后验证

- 旧结果容器标记必须消失或容器被替换；
- 页面必须完成加载；
- 结果容器必须出现；
- 搜索框值必须等于请求关键词；
- 检索条件区域存在时必须包含请求关键词；
- 隐藏关键词存在时必须等于请求关键词；
- 当前子库和隐藏子库字段必须等于请求子库；
- 检索字段必须与标题/关键词模式一致；
- 页码必须重置为 1；
- 连续两次采样必须得到相同 URL、页码、总页数、结果数、行数、页大小、分组模式和结果签名；
- 超时返回 `SEARCH_TRANSITION_UNCONFIRMED`，进入人工继续；
- 已返回页面与请求身份不一致时返回 `RESULTS_STALE`，不继续向下处理。

### 任务接入

- 单篇和批量调用检索时传入实际 `matchMode`；
- 单篇和批量搜索结果必须通过 `require_search_session()` 才能读取行；
- 第一页检索完成后立即写入 checkpoint，再进入暂停/停止安全边界；
- 每次翻页验证同一 `searchId`、预期页码和当前结果身份；
- `single.search-page` 和 `batch.page-scanned` 事件包含 `searchId` 和结果签名；
- 批量开始下载前再次读取当前页并验证目标批次页码、子库和检索身份；
- 批量处理 checkpoint 保存当前批次的 `searchIdentity`；
- 旧任务缺少 `SearchSession` 时记录 `MISSING_SEARCH_SESSION` 和 `controlled_research`；
- 检索失败发生在任务项生成之前，因此旧 DOM 不会创建任务项、打开详情或触发下载；
- 页面连接短暂断开时 BrowserBridge 刷新目标句柄并重试一次；
- 保留阶段 C 租约、启动幂等、暂停、恢复、停止、年份、分页上限、规模确认、来源治理和归档删除语义。
