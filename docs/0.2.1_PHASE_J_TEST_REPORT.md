## 发布构建

### 构建命令

```text
pnpm build:portable
pnpm package:source
pnpm verify:portable
```

结果：全部通过。

阶段 J 修复了发布构建的两个问题：

1. `sitecustomize.py` 原本无条件导入 `coverage`。现已改为仅在
   `COVERAGE_PROCESS_START` 存在时启用，避免污染生产环境；
2. 便携构建原本只清理 stage 下的 `resources/app` 和
   `resources/engine`，可能把上一次运行留下的 `数据`、SQLite 和日志
   带入新 ZIP。现改为每次在 `release` 边界内重建完整 stage 目录。

源码打包同时排除了：

- `outputs`；
- `runtime`、`clean-room` 和 `release`；
- 覆盖数据库、JSON 和 HTML；
- `node_modules`、构建缓存和 `*.tsbuildinfo`。
