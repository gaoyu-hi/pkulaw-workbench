## 交付内容

### SQLite v5

- `SCHEMA_VERSION` 从 4 升级到 5；
- 新建数据库直接创建 v5 schema；
- v4 数据库自动增加：
  - `tasks.archived_at`
  - `tasks.archive_reason`
- 迁移不会删除已有任务；
- `TaskRecord` 增加 `archivedAt` 和 `archiveReason`；
- `task.list` 新增 `includeArchived` 参数，默认隐藏归档任务。

### 后端生命周期

新增协议：

- `task.archive`
- `task.restore`
- `task.cleanup-preview`
- `task.purge`

新增能力标记：

- `tasks.lifecycle.v1`

归档、恢复和删除都在 SQLite 事务中完成。活动任务和活动处理运行会被后端拒绝，不能仅通过隐藏界面误操作。

永久删除依赖既有外键级联，清理：

- `task_items`
- `task_batches`
- `task_events`
- `policy_documents`
- `processing_runs`
- `task_artifacts`

### 清理预览

清理预览只从数据库登记记录中提取文件：

- 任务项 `downloadedFile`
- 任务项/批次 `catalogFile`、`zipFile`、`reportFile`
- `task_batches` 的目录、ZIP 和报告
- `policy_documents` 的 Word、TXT、证据
- 政策 payload 中的官方 HTML/截图
- `task_artifacts` 登记产物

预览对重复路径去重，并标记：

- 不存在；
- 共享给其他任务；
- 输出根目录；
- 路径穿越；
- 非文件；
- 父目录或受保护路径。

未登记文件不会出现在可清理文件列表中。

### Windows 回收站

新增：

- `apps/desktop/src/main/task-file-cleanup.ts`

清理器在 Electron 主进程调用 `shell.trashItem`：

- 去重路径；
- 缺失文件视为无需移动；
- 目录、磁盘根、用户主目录、数据库目录和受保护路径拒绝；
- 任一文件移动失败立即停止，数据库不做删除；
- 全部登记文件成功或明确不存在后，才调用 `task.purge`；
- `task.purge` 再次核验 eligible 文件均已不存在。

支持两种明确动作：

1. 仅删除数据库记录，保留输出文件；
2. 将登记文件移入 Windows 回收站，再删除数据库记录。
