## 交付内容

### 共享年份模型

新增：

```text
engine/pkulaw_engine/selections/years.py
```

支持：

```text
all
single
range
```

校验规则：

- 年份必须为四位数字；
- 最小年份为 2000；
- 最大年份为当前年份；
- 起始年份不能晚于结束年份；
- 年份区间按升序展开。

旧任务中的字符串 `year` 保持兼容：

- `全部年份` 或空值 → 全部年份；
- 四位年份字符串 → 指定年份。

### 执行组合

单篇和批量共用：

```text
关键词 × 子库 × 年份
```

组合记录：

- `queryIndex`
- `libraryIndex`
- `yearIndex`
- `combinationIndex`
- `combinationCount`
- 当前关键词、子库、年份和页码

checkpoint 保存：

- `yearMode`
- `yearStart`
- `yearEnd`
- `currentYear`
- `yearStats`

### 年度状态

每年记录：

- 待执行；
- 执行中；
- 无结果；
- 已完成；
- 暂停；
- 失败。

某年无结果时继续下一年。登录、额度、验证码、页面结构或年份筛选异常会停止父任务。

### 年份筛选缺失

如果非“全部年份”检索无法设置年份筛选或指定年份选项缺失：

```text
YEAR_FILTER_UNAVAILABLE
```

任务会进入 `stopped`，不会把筛选失败当作“没有政策”。

### 去重和批量安全

- 单篇结果按稳定政策 ID 去重；
- 批量扫描维护跨年度 `seen_policy_ids`；
- 同一政策不会因出现在多个年份而重复下载；
- 批量继续时使用批次行内保存的年份；
- 批次文件名加入年份，避免不同年份相同序号范围互相覆盖。
