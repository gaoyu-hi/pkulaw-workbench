- `BrowserBridge` 和 `PkulawAdapter` 共用 AccessState；

- 验证码状态记录实际 selector、尺寸、display、visibility、opacity 和检测时间；
- BrowserHost 状态新增 `captchaSelector`、`captchaBox`、`captchaCheckedAt`；
- 验证码仍可见时 `_user_continue()` 返回 `CAPTCHA_VISIBLE`；

- 设置 `OldPageIndex`、`Pager.PageIndex`、`PageIndex`；
- 支持 `/law/search/RecordSearch` 结果路由；
- 结果页 `ready` 改为页面类型自身的必需控件集合，不再因结果页缺少 `#subLibraries` 失败；
- 翻页确认包含页码、行号、政策 ID、结果签名、查询、检索字段和子库；
- 正常点击成功时不会提交表单；
- 表单回退最多执行一次；
- 错误页、跨检索、签名不变和长期无进展均失败关闭；
- 单篇和批量“已处理，继续”不再吞掉 `CAPTCHA_VISIBLE`；
- 浏览器面板显示验证码命中控件、尺寸和检测时间。
