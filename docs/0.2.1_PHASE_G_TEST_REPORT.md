## 完成内容

### 检索组合上下文

- 新增 `engine/pkulaw_engine/batch_execution.py`；
- 每个“关键词 × 子库 × 年份”组合建立独立 `RetrievalContext`；
- 上下文保存：
  - query
  - library
  - year
  - `searchId`
  - 每页 SearchSession
  - 每页结果签名
  - batchKeys
  - lastPage
- 检索上下文写入任务 checkpoint 的 `retrievalContexts`；
- 扫描结束后的当前 SearchSession 可绑定为活动执行上下文；
- 活动上下文保存当前组合、活动 searchId、当前页和结果签名。

### 页面复用决策

- 当前 SearchSession 与上下文完全匹配且页码等于目标页时直接复用；
- 当前页在目标页之前时只向前翻页；
- 当前页在目标页之后时重新搜索一次；
- 不同检索组合不复用页面；
- 旧 searchId、查询、子库、年份或结果签名不一致时重新搜索；
- 重新搜索仍通过完整 SearchTransaction、筛选、页大小和不分组门禁；
- 重搜后的页面结果签名仍必须与扫描上下文一致；
- 结果签名变化时返回 `BATCH_RESULTS_CHANGED`，安全停止；
- 批次搜索、复用和翻页次数写入 checkpoint。

### 下载前身份核验

- 批次开始前验证 SearchSession 的查询、子库、年份、筛选值、页大小、分组和页码；
- 验证结果行数量；
- 验证每行序号、政策 ID 和标题；
- 验证目标行范围 rowStart/rowEnd；
- 验证实际勾选集合与预期政策 ID 集合完全一致；
- 选择批次后再次执行相同验证；
- 暂停边界恢复后、创建目录 intent 前再次验证；
- 目录下载和格式校验完成后，在 ZIP intent 创建前再次验证：
  - searchId
  - 结果签名
  - 页码
  - 行范围
  - 政策 ID
  - 标题
  - 勾选数量
- 批次身份核验写入 checkpoint 的 `batchIdentityVerification`；
- 页面身份在目录校验后发生变化时返回 `BATCH_RESULTS_CHANGED`，不启动 ZIP。

### 批次安全顺序

- 批次选择身份通过后才创建目录下载 intent；
- 目录下载完成后校验真实格式和行身份；
- 目录格式或身份失败时不创建 ZIP intent；
- ZIP 下载前再次校验批次页面与勾选；
- ZIP 下载后校验 CRC、成员、空文件、重复项、路径和身份映射；
- 目录、ZIP、报告均通过后才登记批次完成；
- progress 只在批次完成数变化时推进；
- 已完成批次继续跳过；
- 失败批次继续按原逻辑隔离和精确重试；
- 暂停、继续、停止保持安全原子边界。
