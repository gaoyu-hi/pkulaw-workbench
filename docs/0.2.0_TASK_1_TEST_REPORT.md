## 交付内容

- WebContentsView 等待 HTTP/HTTPS `dom-ready` 后再连接 Python；
- 页面继续加载时允许连接，不等待所有资源结束；
- 每个 WebContentsView 生成一次性目标标记；
- 连接参数传递实际目标 URL、入口 URL、Session、视图 ID 和目标标记；
- Python 排除 `file://` 应用渲染页；
- Python 优先按目标标记绑定标签页；
- 标记丢失时按实际目标 URL 回退；
- 仍有多个无法确认的 HTTP 页面时失败关闭，不猜测目标；
- BrowserBridge 保存已绑定标签页，跨域导航后继续使用同一个句柄；
- 页面加载事件在绑定前不调用 `browser.state`；
- BrowserHost 新增 `viewLoaded`、`targetBound` 和 `targetUrl`；
- 浏览器界面分别显示后端、网页、Python 绑定和登录状态；
- reconnect 共用同一 Promise，防止重复连接不同标签；
- reconnect 前重新写入目标标记；
- 保留 WebContentsView 重建、Python 重启、renderer 崩溃恢复和下载生命周期。
