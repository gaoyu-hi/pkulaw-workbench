## 完成内容

### V6 selector profile

- 版本升级为 `pkulaw-v6-2026-11-01-3`；
- 补齐年份、省份、时效性三个树形筛选根节点；
- 筛选候选支持 `a.level0`、`a[cluster_code]` 和 `.node_name`；
- 补齐 `.articleSelect`、`#recordPage`、`#recordPage dd` 和隐藏 `Pager.PageSize`；
- 不分组控件继续使用 `input[name="group"][value="2"]`；
- fixture profile 保持独立，并补充同样的页大小和不分组测试控件。

### 筛选器

- 基础检索先提交，筛选在结果页执行；
- 年份、省份和时效性按顺序逐个应用；
- 可见文本、`title` 和 `node_name` 均可作为匹配来源；
- 选项文本尾部的 `(21)`、`（3）` 等数量信息被清理后再精确比较；
- 不支持包含、模糊或近似匹配；
- 筛选项缺失或精确文本不存在时停止；
- 年份缺失返回 `YEAR_FILTER_UNAVAILABLE`；
- 省份或时效性无法应用返回 `FILTER_NOT_APPLIED`；
- 每个成功筛选都插入一次性结果容器标记并等待新的稳定观察；
- 筛选后的 SearchSession 保持同一 `searchId`，但替换筛选值、结果数、签名、URL 和观察时间；
- 旧 SearchSession 不得作为最终结果继续使用。

### 每页条数

- 页大小在筛选完成后执行；
- 支持 10、20、50、100 条；
- 优先使用真实可见 `.articleSelect` 和 `#recordPage dd`；
- 选择项按 `N 条/页` 中的精确数字匹配；
- 回读可见页大小和隐藏 `Pager.PageSize`；
- 显示值必须等于隐藏值并等于请求值；
- 非尾页实际行数必须等于页大小；
- 单页或尾页实际行数必须等于剩余结果数；
- 页大小控件缺失、选择项缺失、显示/隐藏值不一致或行数不自洽时返回 `PAGE_SIZE_NOT_APPLIED`；
- 页大小变化后页码必须重置为 1。

### 不分组

- 页大小完成后执行不分组；
- 已选中时不重复点击；
- 未选中时点击 `input[name="group"][value="2"]`；
- 分组切换必须产生新的稳定 Results DOM；
- SearchSession 必须回读 `groupingMode=ungrouped`；
- 控件缺失、点击失败或回读仍为 `grouped` 时返回 `RESULT_GROUPING_UNAVAILABLE`；
- 分页和结果列表必须在分组变化后重新稳定。

### SearchSession 与 checkpoint

- SearchSession 新增：
  - `actualYear`
  - `actualProvince`
  - `actualTimeliness`
- 最终可消费状态额外要求：
  - 三个筛选值精确匹配；
  - 实际页大小等于请求页大小；
  - 页行数符合非尾页/尾页规则；
  - `groupingMode=ungrouped`；
- 单篇和批量通过 `require_refinements=True` 校验最终结果；
- checkpoint 中的 `searchIdentity` 保存实际筛选值、实际页大小和不分组状态；
- 暂停、停止和恢复均保留该最终检查，不跳过筛选回读。
