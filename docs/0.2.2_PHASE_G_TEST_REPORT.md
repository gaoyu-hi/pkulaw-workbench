## 发现并修复的问题

### 1. 125% 缩放快捷键取整错误

首次阶段 2 烟测中，`Ctrl +` 从 125% 跳到 140%，而不是 135%。

原因：

- 步进函数按一位小数取整；
- `1.25 + 0.1 = 1.35` 被取整为 `1.4`。

修复：

- 增加 1.25 倍步进失败测试；
- 步进改为两位小数；
- 实测 `Ctrl +` 后为 135%，`Ctrl -` 回到 125%，`Ctrl 0` 回到 100%。

### 2. 旧的批量标题成功夹具

全量回归和阶段 4 首次烟测仍存在批量精确标题成功路径。

修复：

- BatchManager 配置解析增加
  `BATCH_EXACT_TITLE_UNSUPPORTED`；
- 控制测试和 Electron 批量夹具改回关键词模式；
- 未恢复“批量标题冒充关键词”的旧行为。

### 3. 多批 ZIP 烟测超时过短

阶段 4 的 4 批和 11 批安全冷却流程在旧 90/120 秒上限内未能完成。

修复：

- 只提高烟测等待上限，分别覆盖完整多批流程；
- 产品 65 秒批次 ZIP 冷却、目录后 ZIP、暂停停止和原子登记边界未改变；
- 最终 11 批全部完成。

### 4. 规模确认后的旧断言

旧烟测期待确认后的实际行数和批次数仍为 0，与阶段 F 的实现不符。

修复：

- 改为验证实际结果不少于 500 条；
- 批次数必须等于 `ceil(实际行数 / 50)`；
- 最终实际统计为 501 条、11 个批次。
