## 交付内容

- 保留独立夹具配置 `sources/profiles/fixture.json`；
- 新增独立真实 V6 配置 `sources/profiles/pkulaw-v6.json`；

  - profile ID、版本和页面特征标记；

- `PkulawAdapter.search()` 在提交检索前完成 profile 诊断；
- 新增 `browser.selector-diagnostics` 后端协议；
- BrowserHost 新增 profile、版本、就绪状态、说明和完整诊断结果；
- 浏览器页和设置与诊断页显示 profile 与适配状态；
- 单篇、批量和任务中心启动门禁要求：
  - 浏览器目标已绑定；
  - 机构已认证；
  - 当前页面选择器诊断通过。
- PyInstaller spec 打包独立 profile 目录；
- 本地阶段 2 新增稳定、兜底、多候选、缺输入和缺按钮夹具；
- 修复任务停止后停留在详情页，恢复时无法识别夹具 profile 的回归；
- 未知页面先检查登录、滑块和额度，再回机构入口重新识别，仍无法识别时失败关闭。
