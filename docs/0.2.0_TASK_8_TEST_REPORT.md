## 交付内容

### 共享分页模型

新增：

```text
engine/pkulaw_engine/selections/pagination.py
```

支持：

- `last`：逐检索组合扫描到真实尾页；
- `limit`：扫描到指定上限后请求人工确认；
- 指定上限最小值为 1；
- 旧数字 `maxPages` 兼容为 `limit`；
- 用户选择“继续到尾页”后，将 `pageMode=last` 持久化到 checkpoint；
- 后续停止和重启继续使用尾页决定。

单篇和批量任务均按：

```text
关键词 × 子库 × 年份
```

独立读取每个组合的 `totalPages`，不使用跨年度共享的固定总页数。

### 分页断点与保护

checkpoint 新增或更新：

- `pageMode`
- `pageSelection`
- `totalPages`
- `currentPage`
- `scannedPages`
- `unscannedPages`
- `combinationTotals`
- `pageLimitGate`
- `pageLimitDecision`

达到上限且真实总页数更大时：

```text
status = waiting_manual
code = PAGE_LIMIT_REACHED
```

页面不前进、页码重复、总页数下降、页码越界或结果签名不变时安全暂停。翻页期间 DrissionPage 的短暂页面上下文丢失会等待页面稳定后重试。

### 批量规模估算

批量任务保存三个阶段的规模：

- `before_scan`：根据检索组合数形成结构估算；
- `after_first_results`：根据首批真实总页数和结果数投影；
- `after_scan_complete`：使用实际扫描页数、去重政策数和 50 条批次数。

投影或实际规模达到任一阈值时进入：

```text
status = waiting_manual
code = BATCH_SCALE_CONFIRMATION_REQUIRED
```

阈值为：

- 20 页；
- 500 条政策；
- 5 个批次。

确认规模前不会创建或下载批次。
