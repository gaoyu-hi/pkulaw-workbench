## 完成内容

### 操作级选择器稳定性

- 新增 `diagnose_for_operation()`；
- 默认等待窗口 5 秒；
- 默认采样间隔 250 毫秒；
- 至少连续两个样本通过才视为稳定；
- 控件短暂缺失后恢复时继续等待；
- 已稳定后再次缺失会清空连续计数；
- 页面可识别但控件持续缺失时返回 `PAGE_SELECTOR_MISMATCH`；
- 控件反复出现和消失时返回 `PAGE_SELECTOR_UNSTABLE`；
- 无法识别页面时返回 `PAGE_SELECTOR_MISMATCH`；
- 每次诊断保留操作名称、必需控件、缺失快照和稳定样本数。

操作门禁：

- `search`
- `read-results`
- `select-batch`
- `download-catalog-trigger`
- `download-catalog-submit`
- `download-zip-trigger`
- `download-zip-submit`
- `read-detail`
- `download-word`

页面/操作修正：

- `_ensure_search_page()` 使用页面级 `pageReady`，不再要求结果页同时具备全部搜索控件；
- 结果页短暂缺少 `libraryRoot` 不阻止读取结果、选择批次或下载；
- 搜索页控件抖动时在 5 秒窗口内等待恢复；
- 搜索、翻页、选批、详情和下载操作前分别运行对应操作门禁；
- 稳定门禁只获取短时 bridge transaction，不长时间占用浏览器操作锁。

### 下载意图

新增 `engine/pkulaw_engine/download_intent.py`：

- `DownloadIntent` 保存：
  - `intentId`
  - `taskId`
  - `kind`
  - 预期后缀
  - 预期来源域名
  - 最大下载次数
  - 创建时间
- `DownloadIntentManager` 原子维护意图和匹配状态；
- started 必须匹配预期后缀和来源域名；
- completed/failed 必须与 accepted started 使用同一 `downloadId`；
- progress 只接受已绑定 downloadId；
- 无关后缀、跨主机和未绑定 completed 只记录 `DOWNLOAD_EVENT_MISMATCH`；
- 同一 intent 的第二个匹配 started 触发 `DOWNLOAD_INTENT_EXHAUSTED`；
- intent 记录文件校验结果和实际格式；
- 下载意图状态可查询；
- BrowserBridge 提供 intent 创建、等待和校验登记接口。

任务接入：

- 单篇 Word intent：`.doc`、`.docx`；
- 批量目录 XLSX intent：`.xlsx`；
- 批量目录 XLS/XLS-XLS intent：`.xls`；
- 批量 ZIP intent：`.zip`；
- 政府官网 Word 附件 intent：`.doc`、`.docx`；
- 原 Word、目录、ZIP 校验器继续检查真实文件结构；
- 校验通过后才把 intent 标记为有效并登记任务结果；
- 单篇任务项 payload 保存 intent 和下载事件摘要；
- 批量 checkpoint 保存目录/ZIP intent ID 与 Download ID；
- 目录 intent 与 ZIP intent 必须不同；
- 任务暂停、停止仍在下载、CRC 和格式校验完成后的安全边界执行。

### Windows 文件名

- 导出统一的 `sanitizeDownloadFilename()`；
- 规范化 Unicode；
- 替换 Windows 非法字符和控制字符；
- 去除开头空白/点、结尾点和空格；
- 处理 `CON`、`NUL`、`COM1` 等保留名；
- 保留短扩展名并限制安全长度；
- 相同文件名通过每个下载事件独立 UUID 目录隔离；
- 下载目标目录创建失败时：
  - 生成同一下载事件的 started/failed；
  - 返回 `DOWNLOAD_DIRECTORY_UNAVAILABLE` 结构化错误；
  - 取消 Electron DownloadItem。
