# 北大法宝 Electron 采集器真实站点、任务控制与记录管理设计

**版本：** 0.2.0 设计稿  
**日期：** 2026-11-01  
**状态：** 0.2.0 本地实现、发布候选和真实第一页只读验收已完成；真实下载/多页/批量验收待授权  
**范围：** 真实站点适配、暂停/继续/停止、任务记录管理、年份与分页  
**运行约束：** 保留 Electron 内置浏览器和 Python/DrissionPage；正常使用不依赖 Agent 或在线模型

## 1. 背景

阶段 6 的本地夹具、便携运行时和诊断已通过，但真实校园网测试暴露了以下问题：

1. 账号已在 Electron 内置浏览器登录，但 Python 曾出现“页面目标为 0”，网页会话有效不等于 Python 已绑定标签页。
2. 学校代理会从 `libproxy.cug.edu.cn` 跳转到 `libresource.cug.edu.cn` 和统一身份认证域名。当前按入口域名筛选标签页，不能完整覆盖这条链路。
3. 真实页面 `#txtSearch` 存在，但程序配置的 `#pkulaw-search-submit` 不存在；真实普通检索按钮为 `#btnSearch`。
4. 当前真实页面适配仍主要依赖夹具选择器，真实结果页、筛选、分页、详情和下载流程尚未完成迁移。
5. 当前只有停止和人工继续，没有用户可以主动使用的暂停；停止依赖协作式检查点。
6. 任务记录不能多选、归档、恢复或删除。
7. 新版年份选项被写死为 `2026–2010`；原 GUI 为 `2000–2026`。
8. “最多页数”默认值为 5，不能选择尾页；指定上限小于真实总页数时直接报错。
9. 原 GUI 没有用户主动暂停按钮，但具备登录、滑块、页面不稳定时自动暂停，以及“继续后重新核验当前步骤”的语义。

## 2. 目标

- 真实北大法宝 V6 页面可被稳定识别、绑定、检索和诊断。
- 跨域登录跳转后，Python 仍绑定到同一个 Electron 网页标签。
- 任务具备自动暂停、手动暂停、继续、停止和断点恢复。
- 任务记录可多选、归档、恢复和按明确边界删除。
- 年份支持全部年份、指定年份和年份区间。
- 分页支持扫描到尾页和指定上限。
- 所有失败都在产生错误文件或消耗下载额度前安全停止。
- 保持阶段 5 的来源治理、政府官网回退和 SHA-256 规则不变。

## 3. 非目标

- 不在正常运行时调用 Agent、大模型或 Codex。
- 不通过北大法宝内部 API绕过网页授权、额度、滑块或学校代理。
- 不在真实站点直接开始大批量下载。
- 不把父级输出目录视为任务独占目录并递归删除。
- 不改变“宽泛关键词不自动回退政府官网”的边界。

## 4. 真实站点连接与页面适配

### 4.1 浏览器目标识别

Electron 创建 `WebContentsView` 后，以以下信息建立目标指纹：

- 当前 `webContents` 的页面 URL；
- 页面是否为应用自身 `file://` 渲染页；
- 当前机构 Session；
- 当前任务浏览器视图标识；
- DOM 就绪状态。

Python 连接随机回环调试端口后，不再只用 `entryUrl` 的域名筛选标签页。标签页跳转到学校代理或统一身份认证域名后，仍保持对原目标对象的绑定。

连接顺序调整为：

```text
创建 WebContentsView
→ 等待 dom-ready 或有限加载完成
→ 获取当前真实页面 URL
→ Python 连接调试端口
→ 按目标指纹选择非应用渲染页
→ 建立并保持标签页句柄
→ 进行登录和页面诊断
```

页面继续加载时可以连接，不再等待整页资源全部结束。连接状态必须由成功完成的 `browser.connect` 写入，页面加载事件不能先调用依赖连接的页面状态刷新。

### 4.2 选择器配置

选择器拆分为两套独立配置：

- `fixture`：现有本地测试页面；
- `pkulaw-v6`：真实北大法宝 V6 页面。

程序先根据页面特征识别配置，不根据任务模式或端口猜测。

已知真实选择器：

| 元素 | 首选选择器 |
| --- | --- |
| 搜索框 | `#txtSearch` |
| 普通检索按钮 | `#btnSearch` |
| 精确检索单选项 | `#accurate` |
| 标题检索范围 | `#main_form input[name="SearchKeywordType"][value="Title"]` |

其余真实页面的子库、年份、省份、结果列表、分页、详情页、下载按钮和同名候选选择器，在实现阶段通过只读 DOM 检查补齐。

### 4.3 固定兜底规则

每个关键元素按以下顺序定位：

1. 首选稳定 ID；
2. 稳定的 name、type、placeholder 或按钮文字；
3. 由已识别父容器约束的结构关系；
4. 全部失败时抛出 `PAGE_SELECTOR_MISMATCH`。

兜底规则全部是确定性 DOM 查询，不调用模型，不包含自然语言推理，不向外部发送页面内容。

### 4.4 适配诊断

新增本地诊断项：

- Python 已绑定浏览器；
- 当前页面不是应用自身渲染页；
- 登录状态已确认；
- 搜索框可见可编辑；
- 普通检索按钮可点击；
- 子库入口可识别；
- 年份、省份和时效性筛选可识别；
- 结果标题行可解析；
- 政策 ID 可提取；
- 分页文字可读取；
- 详情页元数据可读取；
- Word 下载入口可识别。

任一关键项失败时，任务启动按钮保持禁用，不生成正式任务。

### 4.5 错误分类

- `BROWSER_VIEW_NOT_READY`
- `PYTHON_BROWSER_NOT_BOUND`
- `BROWSER_TARGET_NOT_FOUND`
- `LOGIN_REDIRECT_IN_PROGRESS`
- `LOGIN_REQUIRED`
- `MANUAL_VERIFICATION_REQUIRED`
- `PAGE_SELECTOR_MISMATCH`
- `SEARCH_CONTROL_MISSING`
- `FILTER_APPLY_FAILED`
- `YEAR_FILTER_UNAVAILABLE`
- `RESULT_PAGE_UNSTABLE`
- `PAGINATION_MISMATCH`
- `DETAIL_PARSE_FAILED`
- `DOWNLOAD_CONTROL_MISSING`
- `INSTITUTION_QUOTA_REACHED`

前端显示用户可理解的中文原因，同时保留错误码写入 SQLite 和日志。

## 5. 任务状态机

### 5.1 状态

在现有状态基础上增加：

- `pausing`：正在完成当前安全步骤；
- `paused`：已暂停；
- `stopping`：正在完成当前安全步骤并停止。

状态关系：

```text
pending
→ preflight
→ running
→ pausing → paused → running
→ waiting_login / waiting_manual → running
→ stopping → stopped
→ completed / partial

preflight / running / paused
→ failed
```

### 5.2 自动暂停

以下情况进入自动暂停：

- 登录失效；
- 滑块、验证码或其他人工验证；
- 页面未完成稳定加载；
- 检索或筛选提交后结果未稳定更新；
- 同名政策需要用户选择；
- 页数上限低于真实总页数；
- 下载结果无法可靠确认但尚未达到硬停止条件。

登录问题使用 `waiting_login`。其他可恢复人工问题使用 `waiting_manual`。

“继续”重新核验当前步骤和当前页面，不从头重新搜索关键词。

### 5.3 手动暂停

用户点击“暂停”后：

1. 写入 `pause_requested`；
2. 状态变为 `pausing`；
3. 完成当前原子步骤；
4. 状态变为 `paused`；
5. Python 线程和浏览器标签保持存活；
6. 用户点击“继续”后清除暂停信号并从当前检查点继续。

原子步骤包括：

- 当前检索提交；
- 当前列表页读取；
- 当前详情页读取；
- 当前 Word 下载及校验；
- 当前批次目录和 ZIP 下载及校验；
- 当前政策 TXT/证据写入。

暂停和停止不会截断正在写入的文件或正在下载的 ZIP。

### 5.4 停止

用户点击“停止”后：

1. 写入 `stop_requested`；
2. 状态变为 `stopping`；
3. 当前原子步骤完成后退出任务线程；
4. 状态变为 `stopped`；
5. 已确认文件、批次和检查点全部保留。

如果浏览器调用长时间不返回：

- UI 显示“正在等待当前浏览器操作返回”；
- 不提前显示“已停止”；
- 超过安全时限后提供带确认的“强制结束任务”；
- 强制结束必须标记 `forced=true`，下次恢复前重新核验最近文件和检查点。

### 5.5 应用关闭和重启

- 正常关闭：未完成任务先进入停止流程。
- 应用异常中断：启动后将残留的活动状态标记为 `stopped`，错误码 `APPLICATION_INTERRUPTED`。
- 手动暂停：保留 `paused`；重启并重新绑定浏览器后可继续。
- 继续前必须重新通过浏览器、登录和选择器诊断。

### 5.6 按钮显示

| 当前状态 | 可用按钮 |
| --- | --- |
| `preflight` / `running` | 暂停、停止 |
| `pausing` | 停止（禁用暂停） |
| `paused` | 继续、停止 |
| `waiting_login` / `waiting_manual` | 已处理并继续、停止 |
| `stopping` | 无，显示停止进度 |
| `stopped` | 继续、重试失败项 |
| `partial` / `failed` | 重试失败项、查看报告 |
| `completed` | 查看报告 |

### 5.7 安全异常

- 登录、额度和页面安全异常不会因普通“继续”自动放行。
- 机构额度耗尽属于硬停止。
- 页面结构变化默认停止整个任务，避免对后续政策继续误操作。
- 单条普通下载失败可按现有规则继续其他政策，并记录失败项。

## 6. 任务记录管理与删除

### 6.1 选择

- 任务中心每行增加复选框；
- 支持单选、多选；
- 支持“全选当前筛选结果”；
- 不默认选择未显示在筛选结果中的任务；
- 批量操作栏显示选中数量。

### 6.2 回收站

普通任务列表不直接永久删除。默认“删除”实际执行归档：

- 写入 `archived_at`；
- 任务从正常列表隐藏；
- SQLite 数据和输出文件保持不变；
- 回收站可恢复。

活动任务（`preflight`、`running`、`pausing`、`paused`、`waiting_login`、`waiting_manual`、`stopping`）不能归档或永久删除，必须先停止。

### 6.3 彻底删除

回收站提供两个明确动作：

1. `彻底删除记录，保留输出文件`；
2. `彻底删除记录，并将任务产物移入 Windows 回收站`。

文件清理边界：

- 只处理数据库登记的任务项文件、政策 Word/TXT/证据、目录、ZIP、报告和待核验 JSON；
- 不删除用户选择的父级输出目录；
- 不递归删除输出根、磁盘根、用户主目录或未登记文件；
- 文件通过 Electron `shell.trashItem` 移入 Windows 回收站；
- 只有全部已登记文件成功移除或明确不存在后，才删除 SQLite 记录；
- 部分文件失败时保留 SQLite 记录并显示失败文件，可重试。

### 6.4 数据库

SQLite 升级到 v5，新增：

- `tasks.archived_at TEXT`；
- `tasks.archive_reason TEXT`。

彻底删除 `tasks` 行时继续使用现有外键级联，清理：

- `task_items`
- `task_batches`
- `task_events`
- `policy_documents`
- `processing_runs`
- `task_artifacts`

旧 v1–v4 数据库自动迁移，不删除已有任务。

## 7. 年份筛选

### 7.1 模式

- 全部年份；
- 指定年份；
- 起始年份至结束年份。

默认可选范围为 `2000` 至当前年份，与原 GUI 保持一致。结束年份不能早于起始年份。

### 7.2 区间展开

年份区间按升序展开。例如 2018–2021：

```text
2018 → 2019 → 2020 → 2021
```

每个“关键词 × 子库 × 年份”分别执行检索和保存检查点。

### 7.3 失败处理

- 某一年明确无结果：继续下一年；
- 某一年人工暂停：保持当前年份和页码，继续后重试当前步骤；
- 某一年额度耗尽、登录失败或页面结构变化：停止整个父任务；
- 网站未提供请求的年份筛选项时，以 `YEAR_FILTER_UNAVAILABLE` 安全停止，不能把“找不到筛选项”误记为没有政策；
- 所有年份结果按稳定政策 ID 去重；
- 报告记录已完成、无结果和失败年份。

### 7.4 兼容

旧任务中的字符串 `year` 继续按单一年份或全部年份解释。新任务保存结构化：

```json
{
  "yearMode": "all | single | range",
  "year": "2020",
  "yearStart": 2018,
  "yearEnd": 2021
}
```

## 8. 分页模式

### 8.1 模式

- `last`：扫描到尾页，默认模式；
- `limit`：指定页数上限，最小值为 1。

不再默认显示 5。

### 8.2 尾页

尾页按每个“关键词 × 子库 × 年份”分别计算：

- 首次结果页读取 `totalPages`；
- 每次只点击一次下一页；
- 页码不前进、重复结果、总页数下降或页面不稳定时自动暂停；
- 到达各自尾页后继续下一检索组合；
- 不把所有检索组合共用一个固定总页数。

### 8.3 指定上限

指定上限保留原 GUI 防漏抓语义：

- 若真实总页数小于等于上限，正常扫描；
- 若真实总页数大于上限，不截断、不标记完成；
- 进入 `waiting_manual`，错误码 `PAGE_LIMIT_REACHED`；
- 用户可选择“继续到尾页”或“停止任务”；
- 选择尾页后保存 `pageMode=last` 并继续；
- 停止时记录已扫描页数和未扫描页数。

### 8.4 批量规模提示

批量任务在首屏解析总页数后显示：

- 预计扫描页数；
- 预计政策行数；
- 预计 50 条批次数；
- 当前选择的年份数量；
- 是否包含“中央 + 地方”双库。

退化为尾页会显著增加请求数时，要求用户再次确认。

### 8.5 兼容

旧任务中的数字 `maxPages` 解释为 `pageMode=limit`。新任务同时保存：

```json
{
  "pageMode": "last | limit",
  "maxPages": 10
}
```

`pageMode=last` 时 `maxPages` 不参与结束条件。

### 10.3 真实站点门禁

第一条真实测试使用精确标题，只执行检索和结果读取，不下载 Word：

1. 用户已在 Electron 内完成学校登录；
2. 诊断显示四项连接状态全部通过；
3. 搜索框、检索按钮和结果行可读取；
4. 只扫描第一页；
5. 不点击 Word 下载。

通过后，由用户提供一条明确测试标题，再执行一条 Word 下载。真实批量下载必须另行确认。

## 12. 风险和约束

- 北大法宝真实页面仍可能改版，选择器必须版本化并可由诊断定位。
- 年份区间会明显增加请求次数，界面必须在开始前显示数量。
- 尾页模式可能触发机构额度，批量任务必须显示规模并在真实大批量前人工确认。
- Windows 回收站依赖系统 `shell.trashItem`；文件被占用时不删除数据库。
- 强制结束可能留下未确认临时文件，恢复前必须重新校验。
- 本地夹具通过不代表真实站点通过；发布记录必须分开列示。

## 13. 验收标准

- 学校代理跨域登录后，Python 始终绑定正确的 Electron 网页目标。
- 真实搜索框和 `#btnSearch` 可被识别，适配诊断通过。
- 选择器缺失时不生成正式空任务，不消耗下载额度。
- 自动暂停、手动暂停、继续和停止状态清晰且可恢复。
- 任务记录可多选归档、恢复和按边界彻底删除。
- 年份支持全部、单年和区间，默认范围为 2000 至当前年份。
- 分页支持尾页和指定上限，尾页按每个检索组合独立计算。
- 旧 SQLite 和旧任务参数兼容迁移。
- 阶段 5 来源治理和 SHA-256 规则无回归。
- 整个运行链路不依赖 Agent、大模型或 Codex。
