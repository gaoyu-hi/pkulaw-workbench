# 法宝工作台统一任务与浏览器工作区设计

**日期：** 2026-11-03

**状态：** 设计已确认，实施计划已编写

**基线：** `61c469d` / `v0.2.2-hotfix.1`

**范围：** 总览机构配置、逐篇/批量创建与运行界面、内置浏览器、验证码人工处理、自动恢复、任务设置更新

## 1. 目标

把当前“创建表单、任务详情、独立浏览器页”三处来回切换的流程，改成一个固定的一屏工作区：

1. 总览承担机构配置和登录入口；
2. 侧边栏不再保留独立“内置浏览器”页面；
3. 创建任务时只有一个“创建并开始”按钮；
4. 任务运行后，任务状态与内置浏览器左右同屏；
5. 验证码由人工完成，程序自动检测清除并恢复原任务；
6. 中途打开“任务设置”时，浏览器自动收起；
7. 外层应用不滚动，只有内置浏览器保留上下、左右滚动和缩放。

程序不得自动识别、破解或绕过登录、滑块、验证码或机构额度。

## 2. 已确认的产品决策

### 2.1 侧边栏

侧边栏删除“内置浏览器”入口，保留：

- 总览；
- 逐篇采集；
- 批量采集；
- 任务中心；
- 数据与报告；
- 设置与诊断。

内置浏览器改为可复用工作区组件，分别供总览机构登录和任务运行界面使用，不再拥有独立导航页。

### 2.2 总览

删除总览顶部没有实际操作的宣传区和圆形装饰，不保留大幅 Hero 区域。

总览顶部改为机构工作区：

- 未配置或未认证时，左侧显示机构配置，右侧自动显示内置浏览器；
- 已认证时，浏览器自动收起，仅显示机构状态卡；
- 状态卡显示机构名称、授权入口、登录状态、选择器诊断和网页缩放；
- 提供“打开机构页面”“切换账号”“重新检测”操作；
- 配置和认证完成后，突出显示“进入逐篇采集”和“进入批量采集”。

机构工作区不保存账号密码，不导出 Cookie，不代替用户完成登录和验证码。

### 2.3 任务运行界面

任务启动后进入固定运行态，不显示整张创建表单。

桌面宽屏布局为：

```text
┌侧边栏┐┌ 顶部栏 ────────────────────────────────┐
│      │├────────────────────┬──────────────────┤
│      ││ 任务状态与进度     │ 内置浏览器       │
│      ││ 断点、当前组合     │                  │
│      ││ 自动恢复与错误     │ 网页内部滚动     │
│      ││ 最近结果与操作     │ 网页独立缩放     │
│      │└────────────────────┴──────────────────┘
└──────┘
```

- 右侧浏览器从内容区顶部贯穿到底部，不与任务区上下堆叠；
- 左侧任务区只显示必要状态、进度、断点、当前组合、人工动作和错误；
- 原始日志、完整时间线、长 JSON 和低层诊断放入弹窗；
- 运行态外层页面固定，不出现主导航以外的垂直滚动；
- 浏览器 `WebContentsView` 保持自己的滚动和 50%–200% 缩放。

### 2.4 任务设置

运行中的单一任务不再显示“新建任务”按钮，统一显示“任务设置”。

- 点击“任务设置”后，浏览器自动收起；
- 任务设置在原工作区展开，不跳到其他页面；
- 关闭或应用设置后，浏览器自动恢复；
- 只查看、不保存时不暂停任务，也不改变任务状态；
- 没有实际修改就关闭时，任务继续原运行状态。

## 3. 创建与直接开始

删除用户界面中的：

- “预览（0 下载）”独立按钮；
- 独立预览卡；
- “必须先预览才能开始”的第二次点击流程。

单篇和批量均只保留一个主按钮：

- `创建并开始逐篇采集`
- `创建并开始批量采集`

点击后立即创建任务并进入运行工作区，在同一个任务中依次执行：

1. 保存任务配置和配置指纹；
2. 获取任务级浏览器租约；
3. 在运行界面内执行零下载范围核验；
4. 核验结果数、总页数、结果窗口、筛选、页大小和分组；
5. 核验通过后直接开始扫描；
6. 扫描完成后按原任务策略下载；
7. 核验发现截断、规模过大或筛选异常时，在原任务界面进入等待确认。

该流程是“隐藏检前校验”，不是取消安全校验。任何 Word、目录、ZIP 或详情下载都不得发生在范围核验完成之前。

预览能力保留为任务内部组件，不复制任务扫描逻辑：

- 核验结果写入同一任务的 checkpoint；
- 扫描阶段优先复用核验结果；
- 不得因合并按钮而把完整检索执行两遍；
- 任务配置变化后，旧核验结果立即失效。

## 4. 验证码和登录自动恢复

### 4.1 触发

以下状态触发人工处理助手：

- `captchaVisible = true`；
- `loginVisible = true`；
- 任务状态为 `waiting_manual` 或 `waiting_login`，且暂停原因与访问门禁有关。

浏览器始终保持可见，用户直接在网页内完成：

- IP 登录；
- 个人账号登录；
- 账号切换；
- 滑块或验证码。

### 4.2 检测

程序只检测人工操作结果，不模拟人工答案。

检测要求：

- 等待期间约每 1 秒刷新一次访问状态；
- 验证码连续两次不可见；
- 登录页连续两次不可见；
- 机构认证状态连续两次为已认证；
- 页面和选择器重新核验通过。

任意一次重新出现验证码、登录页或页面跳转，稳定计数清零。

### 4.3 自动恢复

稳定清除后，只允许自动恢复最初触发人工等待的那个任务。

恢复操作必须幂等，并自动处理两种状态：

- 任务控制器仍存活：发出人工继续信号；
- 控制器已退出但任务保留可恢复断点：从同一任务断点重新启动工作线程。

不允许根据“当前页面已登录”去恢复其他任务。恢复任务必须由浏览器租约、任务 ID 或暂停上下文唯一确定。

自动恢复只适用于登录和验证码等待，不适用于：

- 同名政策版本选择；
- 分页上限确认；
- 批量规模确认；
- 机构额度硬停止；
- 内容完整性待核验。

### 4.4 用户反馈

任务页在同一位置显示以下状态：

- 等待人工完成登录或验证码；
- 验证码仍可见；
- 验证码已清除，正在复核；
- 正在恢复浏览器门禁；
- 正在从原断点恢复任务；
- 自动恢复成功；
- 自动恢复失败，可重新检测。

自动恢复失败时提供“重新检测并继续”按钮，但不要求用户重新翻找任务。

## 5. 中途修改任务设置

运行中修改检索条件会改变任务身份和断点含义，不能直接混用旧扫描日志。

### 5.1 打开设置

- 浏览器边界收起，`WebContentsView` 仍然存活并保持 Session；
- 任务继续运行，除非用户点击“应用设置”；
- 表单读取当前任务配置，不以另一任务的草稿覆盖。

### 5.2 应用设置

点击“应用设置”后：

1. 比较新旧配置指纹；
2. 没有差异时直接关闭设置并恢复浏览器；
3. 有差异时在当前安全步骤边界暂停任务；
4. 保留已完成条目、已完成文件和审计记录；
5. 递增配置版本，旧扫描日志和旧核验快照不再作为新配置的起点；
6. 使用同一任务 ID 和新配置重新执行零下载范围核验；
7. 核验通过后从新配置第 1 页开始扫描；
8. 完成后恢复浏览器并继续任务。

已完成文件按稳定政策身份复用，不因重新扫描而重复下载；审计记录必须标明其属于哪个配置版本。

界面不得悄悄创建第二个同名任务，也不得让旧年份、旧关键词的扫描进度冒充新设置结果。

## 6. 浏览器工作区边界

### 6.1 可复用组件

新增统一的 `BrowserSurface` 视觉组件，负责：

- 地址、后退、刷新、主页；
- 网页缩放；
- `WebContentsView` 的显示区域和边界；
- 当前机构、登录和验证码状态；
- 收起与恢复；
- 页面内部滚动。

总览、逐篇运行态和批量运行态都使用同一组件，避免各自维护一套布局和状态。

### 6.2 滚动与缩放

- `body`、应用外壳、侧边栏、顶部栏和任务主区不随页面滚动；
- 浏览器内部保留原生上下、左右滚动；
- `Ctrl +`、`Ctrl -`、`Ctrl 0` 只作用于内置网页；
- 缩放比例继续按机构保存；
- 任务列表、按钮、侧边栏和弹窗不随网页缩放；
- 未认证、任务暂停和设置展开时，不得留下透明或越界的浏览器原生覆盖层。

## 7. 状态与数据契约

### 7.1 界面模式

采集相关界面明确分为：

- `configure`：创建任务设置；
- `running`：任务与浏览器左右工作区；
- `settings`：运行中任务设置展开、浏览器收起；
- `manual`：登录或验证码人工处理；
- `decision`：同名、页数上限或规模确认。

### 7.2 任务恢复上下文

任务 checkpoint 增加可供恢复的上下文：

- 等待类型；
- 配置版本；
- 浏览器租约任务 ID；
- 自动恢复是否已尝试；
- 最近一次稳定检测时间；
- 自动恢复结果和错误码。

恢复上下文不得保存账号、密码、Cookie 或验证码答案。

## 8. 错误处理

- 浏览器视图不存在：显示“重新打开机构页面”，不假装已认证；
- Session 失效：总览状态卡显示未认证，任务保持人工等待；
- 验证码重现：取消本轮自动恢复；
- 自动恢复请求重复：通过 operationId 只执行一次；
- 设置应用时任务无法进入安全边界：保留设置草稿并提示停止原因；
- 旧配置结果与新配置冲突：保留旧结果作为历史记录，新配置扫描写入新版本；
- 内部门禁失败：不启动下载，任务保持可恢复状态。

## 9. 测试与验收

### 9.1 布局

- 以至少 1536×864 逻辑像素为“完整展开”的一屏基准；在
  1920×1080 物理分辨率、125% 显示缩放下等效应达到同一基准；
- 基准尺寸下任务进度、当前组合、断点和浏览器同屏；
- 基准尺寸下外层没有主垂直滚动，低优先级详情通过弹窗查看；
- 低于基准尺寸时，次要任务卡可切换为紧凑摘要，不能通过恢复外层
  垂直滚动来隐藏浏览器或主要操作；
- 浏览器占右侧完整内容高度，不在任务状态条下方单独换行；
- 任务设置展开时浏览器收起，关闭后恢复原位置；
- 只有浏览器内部出现上下、左右滚动条。

### 9.2 机构配置

- 未配置时总览自动显示机构配置与浏览器；
- 已认证后浏览器收起为状态卡；
- 打开登录和切换账号时浏览器重新出现；
- 登录完成后状态自动更新；
- 侧边栏不存在独立浏览器入口。

### 9.3 直接开始

- 单篇和批量都没有独立预览按钮；
- 点击“创建并开始”后直接进入运行工作区；
- 内部核验期间下载计数始终为 0；
- 核验失败或超规模时在原界面等待确认；
- 核验成功后不重复执行完整检索。

### 9.4 自动恢复

- 模拟验证码出现后，任务进入人工等待；
- 模拟人工清除后，连续两次稳定样本触发自动恢复；
- 验证码短暂闪烁不会触发继续；
- 验证码重新出现时取消恢复；
- 只恢复原始任务，不误启动其他任务；
- 控制器存活与线程已退出两种恢复路径都成功。

### 9.5 设置更新

- 打开设置不改变任务状态；
- 无修改关闭后浏览器恢复；
- 修改检索条件后安全暂停，保留已完成文件，配置版本递增；
- 新配置重新核验并从新扫描范围开始；
- 旧配置与新配置结果不会混合标记为完成。

### 9.6 回归

- 单篇、批量、数据处理、任务中心、诊断和发布包测试保持通过；
- 真实站点仅在明确人工监督下验证登录、验证码检测和单次小规模恢复；
- 验收过程不执行无授权的大规模下载。

## 10. 非目标

- 不自动破解、识别或绕过验证码；
- 不自动输入账号密码；
- 不导出或共享 Cookie；
- 不新增 WPS、PDF、纯文本、超文本、纯净版下载格式；
- 不同时处理 macOS 适配；
- 不删除现有任务、来源证据或已下载文件；
- 不在本设计阶段修改代码或重跑阶段 I 验收。
